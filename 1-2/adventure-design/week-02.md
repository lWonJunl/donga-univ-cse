# Chatper 01. 프로그래밍 언어 개요
## 프로그래밍 언어
* 사람이 컴퓨터에게 지시할 명령어들을 기술하기 위해 만들어진 언어

## 언어 수준
| 구분 | 예시 | 특징 |
| :-- | :-- | :-- |
| 저급 언어 | 기계어, 어셈블리어 | 컴퓨터가 직접 이해하기 쉽지만 사람이 작성하고 읽기 어렵다. |
| 중급 언어 | C | 하드웨어 제어와 고급 언어의 편의성을 함께 제공한다. |
| 고급 언어 | Java, C++, Python | 사람이 작성하기 편리하며 실행을 위해 번역 과정이 필요하다.|

## ⭐ 컴파일러 vs 인터프리터
| 구분 | 컴파일러 | 인터프리터 |
| :-- | :-- | :-- |
| 방식 | 명령어를 기계어로 번역 | 명령어를 한 줄씩 읽어 실행 |
| 장점 | 일반적인 경우 속도가 더 빠르다 | 컴파일 단계를 거치지 않는다 |
| 단점 | 원시 프로그램의 크기가 크면 상당한 시간 소요 | 실행 시간이 느림 |
| 예시 | C | Python |

## 문자 표현 방식 : ASCII vs UNICODE (29.p)
* 코드의 의미
    1. 프로그래밍 코드 
    2. 사람의 언어를 기계어로 바꾼 것
* ASCII 
    * 숫자,영어 1byte / 한글 2byte
    * 8bit 중 7bit만 데이터 비트로 사용
* UNICODE
    * 전 세계 모든 문자 2byte
    * 선 세계의 문자를 일관되게 표현

## 알고리즘 (33.p)
* 알고리즘을 만드는 원리 : 문제분해 - 순차 - 조건 - 반복
* 방법 : 자연어, 의사코드, 순서도

## ⭐ 순서도
### 기본 순서도 기호

| 기호 이름 | 영문 | 용도 |
| :-- | :-- | :-- |
| 단자 | Terminator | 순서도의 시작과 끝을 나타낸다. |
| 처리 | Process | 연산, 값 변경, 데이터 이동 등 실행할 작업을 나타낸다. |
| 입출력 | Input/Output | 일반적인 입력 또는 출력 작업을 나타낸다. |
| 조건·의사 결정 | Decision | 조건의 참·거짓 등에 따라 흐름이 분기됨을 나타낸다. |
| 흐름선 | Flow line | 기호 사이의 처리 순서와 진행 방향을 화살표로 나타낸다. |
| 연결자 | Connector | 같은 페이지 안에서 떨어진 흐름을 이름으로 연결한다. |
| 페이지 연결자 | Off-page connector | 다른 페이지로 이어지는 흐름의 출입구를 나타낸다. |
| 주석 | Comment | 기호나 처리 내용을 보충 설명하며, 점선으로 해당 기호와 연결한다. |

### 추가 순서도 기호

| 기호 이름 | 영문 | 용도 |
| :-- | :-- | :-- |

| 정의된 처리 | Predefined process | 다른 곳에 정의된 서브프로그램 또는 함수를 호출함을 나타낸다. |

| 정렬 | Sort | 데이터를 일정한 기준에 따라 순서대로 배열하는 작업을 나타낸다. |
| 추출 | Extract | 파일에서 필요한 부분만 분리하여 새 파일을 만드는 작업을 나타낸다. |


# Chapter 02. C 프로그래밍 시작
## 프로그램 구현 과정
1. 소스 편집: C 소스 파일을 작성. 하나의 C 프로그램에는 실행 시작점인 `main` 함수가 단 한개만 있어야 한다
2. 컴파일: C 소스 코드를 목적 코드로 번역하고 문법 오류를 검사
3. 목적 파일 생성: 일반적으로 `.obj` 확장자의 목적 파일 생성
4. 링크: 링크 에디터가 여러 목적 파일과 라이브러리를 결합하여 외부 참조를 해결
5. 실행 파일 생성: 운영체제가 실행할 수 있는 파일을 생성
6. 로드: 로더모듈이 실행 파일을 메모리에 적재
7. 실행: CPU가 메모리에 적재된 프로그램을 실행

# Chapter 03. 자료형과 변수
## C언어 자료형과 서식 지정자
* 정수형
    * short - %d
    * int - %d
    * long int - %ld
* 실수형
    * float - %f
    * double - %f 또는 %lf
    * long double - %lf
* 문자
    * char - %c, 1byte
* 문자열
    * char 배열 - %s
* unsigned
    * 맨 처음 비트에 부호를 저장하지 않도록 지정
    * 부호를 저장하지 않으므로 음수 사용 불가

## 컴퓨터에서 숫자 표기법
- 부호와 절대치: 맨 처음 비트가 `0`이면 양수, `1`이면 음수를 의미하고 나머지 비트로 절대값을 표현한다.
- 1의 보수: 양수의 비트를 반전하여 음수를 표현한다.
- 2의 보수: 1의 보수에 `1`을 더해 음수를 표현한다. 현대 컴퓨터의 부호 있는 정수 표현에 주로 사용된다.

k`비트 기준 표현 범위는 다음과 같다.

| 방식 | 범위 |
| :-- | :-- |
| 부호와 절대치, 1의 보수 | `-(2^(k-1)-1)` ~ `2^(k-1)-1` |
| 2의 보수 | `-2^(k-1)` ~ `2^(k-1)-1` |
| `unsigned` | `0` ~ `2^k-1` |

### 6비트 표현 예시

| 숫자 | 부호와 절대치 | 1의 보수 | 2의 보수 |
| :-- | :-- | :-- | :-- |
| +9 | 001001 | 001001 | 001001 |
| -9 | 101001 | 110110 | 110111 |
| +0 | 000000 | 000000 | 000000 |
| -0 | 100000 | 111111 | (overflow) |
| +12 | 001100 | 001100 | 001100 |
| -12 | 101100 | 110011 | 110100 |
