# Chapter 03. 자료형과 변수
## 자료형
* 정수형
    * short - %d
    * int - %d
    * long int - %ld
* 실수형
    * float - %f
    * double - %lf or %f
    * long double - %lf
* 문자
    * char - %c, 1byte
* 문자열
    * char 배열 - %s

## 컴퓨터에서 숫자 표기법
* 부호와 절대치
    * 부호 - 맨 앞 비트가 0이면 양수, 1이면 
* 1의 보수
    * 표현 범위 : -(2^5-1) ~ 2^5-1
* 2의 보수
    * 표현 범위 : -2^5- ~ 2^5-1

* signed
    * 부호와 절대치, 1의 보수 => -(2^(k-1)-1) ~ 2^(k-1)-1
    * 2의 보수 => -2^(k-1) ~ 2^(k-1)-1
* unsigned : 부호X => 범위 0부터 시작
    * 3가지 모두 0 ~ 2^k-1

| 숫자 (6bit) | 부호와 절대치 | 1의 보수 | 2의 보수 |
| :--- | :------ | :------ | :----------- | 
| +9 | 001001 | 001001 | 001001 |
| -9 | 101001 | 110110 | 110111 |
| +0 | 000000 | 000000 | 000000 |
| -0 | 100000 | 111111 | (overflow) |
| +12 | 001100 | 010011 | 010100 |
| -12 | 101100 | 110011 | 110100 |
