# 2주차 1차시

> 수업 날짜: `2026-09-08`

## 배운 명령어

### 1. `adduser`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `adduser 사용자명` |
| 기능 | 새로운 사용자 계정을 생성하고 홈 디렉터리, 그룹, 기본 설정을 자동으로 구성 |
| 옵션 | 없음 |
| 인자 | `사용자명`: 생성할 계정의 이름 |

#### 사용 예시

```bash
sudo adduser hong
```

---

### 2. `useradd`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `useradd [옵션] 사용자명` |
| 기능 | 새로운 사용자 계정을 생성한다. |
| 옵션 | `-m`: 홈 디렉터리 생성<br>`-s 셸`: 로그인 셸 지정<br>`-g 그룹`: 기본 그룹 지정<br>`-G 그룹`: 보조 그룹 지정<br>`-u UID`: 사용자 ID 지정 |
| 인자 | `사용자명`: 생성할 계정의 이름 |

#### 사용 예시

```bash
sudo useradd -m -s /bin/bash hong
```

---

### 3. `passwd`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `passwd 사용자명` |
| 기능 | 사용자의 로그인 패스워드를 설정하거나 변경한다. |
| 옵션 | `-l`: 패스워드를 잠가 로그인 불가 상태로 함<br>`-u`: 잠긴 패스워드를 다시 풀어 로그인 가능하게 함<br>`-d`: 패스워드 삭제<br>`-e`: 패스워드를 만료시켜 다음 로그인 시 변경 요구<br>`-n N`: 최소 N일 후 패스워드 변경 가능<br>`-x N`: 최대 N일 후 패스워드 변경 필요 |
| 인자 | `사용자명`: 비밀번호를 설정하거나 변경할 계정 |

#### 사용 예시

```bash
sudo passwd hong
```

관련 파일: `/etc/passwd`(사용자 계정 정보), `/etc/shadow`(암호화된 패스워드 정보)

---

### 4. `userdel`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `userdel [-r] 사용자명` |
| 기능 | 사용자 계정을 삭제한다. |
| 옵션 | `-r`: 사용자의 홈 디렉터리와 메일 스풀도 함께 삭제 |
| 인자 | `사용자명`: 삭제할 계정의 이름 |

#### 사용 예시

```bash
sudo userdel kim
sudo userdel -r kim
```

---

## 명령어 메모

- 사용자 계정 추가·비밀번호 설정·계정 삭제 명령은 `root` 사용자 또는 `sudo` 권한이 있어야 실행할 수 있다.
- Ubuntu/Debian 계열에서는 여러 설정을 자동으로 처리하는 `adduser` 사용을 권장한다.
- `userdel`을 실행할 때 로그인 중인 사용자는 삭제할 수 없다.
- `userdel -r`은 사용자의 홈 디렉터리도 함께 삭제하므로 신중하게 사용한다.
- `root`, `daemon`과 같은 시스템 계정은 함부로 삭제하지 않는다.
