### 6. `ls`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `ls [옵션] 디렉터리* 파일*` |
| 기능 | 지정한 디렉터리의 내용을 출력한다. 디렉터리를 생략하면 현재 디렉터리의 내용을, 파일을 지정하면 해당 파일의 정보만 출력한다. |
| 옵션 | `-a`: 숨김 파일을 포함한 모든 파일 출력<br>`-s`: 파일 크기를 K바이트 단위로 출력<br>`-l`: 파일의 상세 정보 출력<br>`-F`: 기호로 파일 종류 표시<br>`-R`: 모든 하위 디렉터리의 내용도 출력 |
| 인자 | `디렉터리`: 내용을 확인할 디렉터리<br>`파일`: 정보를 확인할 파일 |

#### 사용 예시

```bash
# 현재 디렉터리 내용 출력
ls

# 루트 디렉터리와 홈 디렉터리 내용 출력
ls /
ls ~

# 디스크 블록 수, 숨김 파일, 상세 정보 출력
ls -s
ls -a
ls -asl

# 파일 종류 표시 및 하위 디렉터리까지 출력
ls -F /
ls -R
```

#### 옵션별 출력 이해

- `ls -a`: `.`(현재 디렉터리)와 `..`(부모 디렉터리)를 포함해 숨김 파일과 디렉터리를 모두 출력한다.
- `ls -s`: 각 항목이 사용하는 디스크 블록 수를 K바이트 단위로 출력한다.
- `ls -F`: 항목 뒤의 기호로 종류를 표시한다. `*`는 실행 파일, `/`는 디렉터리, `@`는 심볼릭 링크이다.
- `ls -R`: 현재 디렉터리뿐 아니라 모든 하위 디렉터리의 내용도 재귀적으로 출력한다.

#### `-l`과 `-s` 출력 항목

`ls -l`은 파일 속성과 파일의 논리적 크기를 출력한다. 크기는 파일에 저장된 실제 데이터의 크기이며 단위는 바이트(byte)이다. `ls -s`는 파일이 디스크에서 실제로 사용하는 공간을 블록 수로 출력한다.

- `ls -l`의 파일 크기: 파일 내용의 논리적 크기(바이트)
- `ls -s`의 블록 수: 디스크에 할당된 공간(기본적으로 1K 블록 단위)
- 작은 파일도 최소 한 블록을 사용할 수 있으므로 두 값은 서로 다를 수 있다.
- 심볼릭 링크는 링크 경로 문자열의 길이가 파일 크기로 표시되지만, 별도 데이터 블록을 사용하지 않아 `ls -s`에서 `0`으로 표시될 수 있다.

`ls -sl`을 실행하면 블록 수가 맨 앞에 추가되고, 그 뒤에 `ls -l`의 상세 정보가 다음 순서로 출력된다.

| 순서 | 항목 | 설명 |
| --- | --- | --- |
| 1 | 블록 수 | `-s` 옵션으로 출력되는 디스크 블록 수 |
| 2 | 파일 종류 | 일반 파일, 디렉터리, 심볼릭 링크 등의 종류 |
| 3 | 접근 권한 | 소유자·그룹·기타 사용자의 읽기·쓰기·실행 권한 |
| 4 | 링크 수 | 파일을 가리키는 하드 링크의 개수 |
| 5 | 소유자명 | 파일 소유자의 이름 |
| 6 | 그룹명 | 파일이 속한 그룹의 이름 |
| 7 | 파일 크기 | 파일의 크기(바이트) |
| 8 | 최종 수정 시간 | 파일이 마지막으로 수정된 날짜와 시간 |
| 9 | 파일 이름 | 파일 또는 디렉터리의 이름 |

```bash
ls -sl cs1.txt
```

### 18. `cat`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `cat [-n] 파일*` 또는 `cat > 파일` |
| 기능 | 파일 내용을 화면에 출력하거나, 표준 입력 내용을 파일로 저장한다. |
| 옵션 | `-n`: 출력할 때 각 줄 앞에 줄 번호 표시 |
| 인자 | `파일`: 내용을 출력하거나 저장할 대상 파일 |

#### 사용 예시

```bash
# 표준 입력으로 파일 만들기: 입력을 마친 뒤 Ctrl+D
cat > cs1.txt

# 파일 내용 출력 및 줄 번호 표시
cat cs1.txt
cat -n cs1.txt
```

`cat > 파일`은 표준 입력 내용을 파일에 저장하며, 파일이 없으면 새로 만든다. `cat`에 파일을 지정하지 않으면 표준 입력 내용을 그대로 출력한다.

#### 파일을 지정하지 않은 경우

파일을 지정하지 않으면 입력한 내용을 그대로 화면에 출력하며, `Ctrl+D`로 입력을 끝낸다.

```console
$ cat
Hello World !
Hello World !
Bye!
Bye!
^D
```

옵션 없이 실행하면 줄 수, 단어 수, 문자 수, 파일 이름 순서로 출력한다. 파일을 지정하지 않으면 표준 입력 내용을 대상으로 한다.

### 24. `vi`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `vi 파일*` |
| 기능 | 터미널에서 사용하는 기본 텍스트 편집기를 실행한다. |
| 옵션 | 없음 |
| 인자 | `파일`: 열거나 새로 작성할 파일 |

#### 사용 예시

```bash
# Vim 설치가 필요한 경우
sudo apt install vim

# 파일 편집 시작

```

`vi`는 명령 모드, 입력 모드, 마지막 줄 모드를 구분해 사용한다. 시작하면 명령 모드이며, `Esc`를 누르면 입력 모드에서 명령 모드로 돌아온다.

#### 마지막 줄 모드 명령

명령 모드에서 `:`를 입력하면 마지막 줄 모드로 전환한다.

| 명령 | 기능 |
| --- | --- |
| `:set nu` | 줄 번호 표시 |

| `:wq` | 저장하고 종료 |

### 명령어 표기 형식

- `디렉터리`: 반드시 한 번 입력해야 하는 인자
- `[디렉터리]`: 선택적으로 입력하는 인자
- `디렉터리+`: 하나 이상의 디렉터리를 입력할 수 있음
- `디렉터리*`: 0개 이상의 디렉터리를 입력할 수 있음
- `파일+`: 하나 이상의 파일을 입력할 수 있음
- `파일*`: 0개 이상의 파일을 입력할 수 있음
- 대괄호(`[ ]`)와 `+`, `*`는 사용법을 설명하기 위한 표기이며 실제 명령어에 입력하지 않는다.
