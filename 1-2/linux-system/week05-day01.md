## 배운 명령어

### 1. `echo`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `echo [-n] [문자열]` |
| 기능 | 문자열을 화면에 출력한다. |
| 옵션 | `-n`: 출력 끝에 줄 바꿈을 하지 않음 |
| 인자 | `문자열`: 출력할 내용 |

#### 사용 예시

```bash
echo welcome to linux
echo "welcome to ubuntu linux"
echo -n "hello"
```

---

### 2. `chsh`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `chsh` |
| 기능 | 로그인할 때 자동으로 실행되는 로그인 쉘을 변경한다. |
| 옵션 | 자료의 예시에서는 사용하지 않음 |
| 인자 | 실행 후 표시되는 프롬프트에 새 로그인 쉘 경로를 입력 |

#### 사용 예시

```bash
# 현재 로그인 쉘 확인
echo $SHELL

# 프롬프트에서 /bin/sh를 입력
chsh

# 로그아웃한 뒤 다시 로그인하여 확인
echo $SHELL
```

로그인 쉘은 `/etc/passwd`의 사용자 항목에 기록된다. 자료의 예시에서는 `chsh`로 쉘을 변경한 뒤 다시 로그인하여 확인한다.

---

### 3. `/bin/sh`, `exit`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `/bin/sh`<br>`exit` |
| 기능 | 현재 쉘에서 `/bin/sh` 서브 쉘을 시작하고, `exit`로 종료해 이전 쉘로 돌아간다. |
| 옵션 | 자료의 예시에서는 사용하지 않음 |
| 인자 | 없음 |

#### 사용 예시

```bash
/bin/sh
exit
```

---

### 4. `명령어 &`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `명령어 &` |
| 기능 | 명령어를 후면에서 실행하여 쉘에서 다른 작업을 계속할 수 있게 한다. |
| 옵션 | `&`: 명령어 끝에 붙이는 후면 실행 기호 |
| 인자 | `명령어`: 후면에서 실행할 명령어 또는 명령어 그룹 |

#### 사용 예시

```bash
(sleep 100; echo done) &
find . -name test.c -print &
```

전면에서 실행한 명령어는 끝날 때까지 쉘이 기다린다. 후면 작업을 시작하면 작업 번호와 프로세스 ID가 표시될 수 있다.

### 5. `jobs`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `jobs [%작업번호]` |
| 기능 | 현재 쉘의 후면 작업을 나열한다. 작업 번호를 지정하면 해당 작업만 표시한다. |
| 옵션 | 자료의 예시에서는 사용하지 않음 |
| 인자 | `%작업번호`: 확인할 작업 번호. 생략하면 작업 목록을 표시 |

#### 사용 예시

```bash
jobs
jobs %1
```

### 6. `fg`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `fg %작업번호` |
| 기능 | 지정한 후면 작업을 전면 작업으로 전환한다. |

| 인자 | `%작업번호`: 전면으로 가져올 작업 번호 |


### 7. `>`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `명령어 > 파일` |
| 기능 | 명령어의 표준출력을 화면 대신 파일에 저장한다. |
| 옵션 | `>`: 표준출력 재지정 기호 |
| 인자 | `파일`: 출력 내용을 저장할 대상 파일 |

#### 사용 예시

```bash
ls -asl > ls.txt
cat ls.txt
ls / > list.txt

# 입력한 내용을 파일에 저장하고 Ctrl+D로 입력 종료
cat > list1.txt
cat > list2.txt

# 두 파일의 내용을 이어 새 파일에 저장
cat list1.txt list2.txt > list3.txt
```

대상 파일에 기존 내용이 있으면 `>`는 그 내용을 덮어쓴다.

### 8. `>>`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `명령어 >> 파일` |
| 기능 | 명령어의 표준출력을 파일 끝에 추가한다. |
| 옵션 | `>>`: 표준출력 추가 기호 |
| 인자 | `파일`: 출력 내용을 덧붙일 대상 파일 |

#### 사용 예시

```bash
date >> list1.txt
cat list1.txt
```

---

### 9. `<`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `명령어 < 파일` |
| 기능 | 명령어의 표준입력을 키보드 대신 파일에서 받는다. |
| 옵션 | `<`: 표준입력 재지정 기호 |
| 인자 | `파일`: 입력으로 사용할 파일 |

#### 사용 예시

```bash
wc < list1.txt
sort -r < ls.txt
```

`wc list1.txt`처럼 파일명을 인자로 전달하는 경우와 달리, `<`는 파일 내용을 표준입력으로 전달한다.

---

### 10. `<<`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `명령어 << 단어` |
| 기능 | 종료 단어가 나올 때까지 입력한 내용을 명령어의 표준입력으로 전달한다. |
| 옵션 | `<<`: 문서 내 입력 기호 |
| 인자 | `단어`: 입력의 끝을 표시할 구분자 |

#### 사용 예시

```bash
wc << END
hello !
word count
END
```

마지막 `END`는 입력 종료를 표시하며 `wc`에 전달되는 내용에는 포함되지 않는다.

### 11. `2>`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `명령어 2> 파일` |
| 기능 | 명령어의 표준오류를 화면 대신 파일에 저장한다. |
| 옵션 | `2>`: 표준오류 재지정 기호 |
| 인자 | `파일`: 오류 메시지를 저장할 대상 파일 |

#### 사용 예시

```bash
ls -l /bin/usr 2> err.txt
cat err.txt
```

`>`는 표준출력, `2>`는 표준오류를 재지정한다.

### 12. `|`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `명령어1 \| 명령어2` |
| 기능 | 첫 번째 명령어의 표준출력을 두 번째 명령어의 표준입력으로 전달한다. |
| 옵션 | `\|`: 파이프 기호 |
| 인자 | `명령어1`: 데이터를 출력할 명령어<br>`명령어2`: 입력을 받아 처리할 명령어 |

#### 사용 예시

```bash
ls | sort -r
who | wc -l
ls 디렉터리 | wc -w
```

파일을 거치지 않고 명령어의 출력 결과를 다음 명령어에서 바로 사용할 수 있다.

### 13. `sort`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `sort -r < 파일`<br>`명령어 \| sort -r` |
| 기능 | 입력받은 줄을 역순으로 정렬한다. 자료에서는 파일 이름 목록을 내림차순으로 출력하는 데 사용한다. |
| 옵션 | `-r`: 정렬 결과를 역순으로 출력 |
| 인자 | `파일`: 정렬할 내용이 들어 있는 파일. 파이프로 입력받을 때는 생략 |

#### 사용 예시

```bash
ls > ls.txt
sort -r < ls.txt
ls | sort -r
```

### 14. `;`, `( )`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `명령어1; 명령어2`<br>`(명령어1; 명령어2)` |
| 기능 | `;`로 명령어를 순서대로 실행한다. 괄호로 묶으면 여러 명령어를 하나의 그룹으로 실행한다. |
| 옵션 | `;`: 명령어 구분 기호<br>`( )`: 명령어 그룹 기호 |
| 인자 | `명령어1`, `명령어2`: 순서대로 실행할 명령어 |

#### 사용 예시

```bash
date; pwd; ls

# 세 명령어의 출력을 함께 파일에 저장
(date; pwd; ls) > out2.txt
```

`date; pwd; ls > out1.txt`에서는 `ls`의 출력만 파일에 저장된다. 괄호로 묶으면 그룹 전체의 출력을 재지정할 수 있다.

### 15. `&&`, `||`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `명령어1 && 명령어2`<br>`명령어1 \|\| 명령어2` |
| 기능 | `&&`는 첫 명령어가 성공하면 다음 명령어를 실행한다. `\|\|`는 첫 명령어가 실패하면 다음 명령어를 실행한다. |
| 옵션 | `&&`, `\|\|`: 실행 결과에 따라 다음 명령어를 선택하는 기호 |
| 인자 | `명령어1`, `명령어2`: 조건에 따라 실행할 명령어 |

#### 사용 예시

```bash
gcc myprog.c && ./a.out
gcc myprog.c || echo 컴파일 실패
```

### 16. 파일 이름 대치 (`*`, `?`, `[ ]`)

| 항목 | 내용 |
| --- | --- |
| 명령어 | `명령어 파일이름패턴` |
| 기능 | 쉘이 명령어를 실행하기 전에 패턴을 일치하는 파일 이름으로 바꾼다. |
| 옵션 | `*`: 빈 문자열을 포함한 임의의 문자열<br>`?`: 임의의 한 문자<br>`[ ]`: 대괄호 안의 문자 중 한 문자(범위 지정 가능) |
| 인자 | `파일이름패턴`: 찾을 파일 이름의 형태 |

#### 사용 예시

```bash
gcc *.c
ls *.txt
ls [ac]*
```

예를 들어 `*.c`는 현재 디렉터리에서 `.c`로 끝나는 파일 이름에 해당한다.

### 17. 명령어 대치 (`$( )`)

| 항목 | 내용 |
| --- | --- |
| 명령어 | `$(명령어)` 또는 백틱으로 감싼 명령어 |
| 기능 | 안쪽 명령어의 실행 결과를 바깥 명령어의 일부로 사용한다. |
| 옵션 | `$( )`: 명령어 대치 표기 |
| 인자 | `명령어`: 먼저 실행하여 출력을 가져올 명령어 |

#### 사용 예시

```bash
echo "현재 시간은 $(date)"
echo "현재 디렉터리 내의 파일의 개수: $(ls | wc -w)"
```

자료에서는 백틱 표기도 소개하며, `$(명령어)`가 같은 용도로 쓰인다고 설명한다.

### 18. 따옴표 (`' '`, `" "`)

| 항목 | 내용 |
| --- | --- |
| 명령어 | `명령어 '문자열'`<br>`명령어 "문자열"` |
| 기능 | 작은따옴표는 파일 이름, 변수, 명령어 대치를 제한한다. 큰따옴표는 파일 이름 대치를 제한하고 변수·명령어 대치는 허용한다. |
| 옵션 | `' '`: 내용을 문자 그대로 취급<br>`" "`: 파일 이름 대치를 제한 |
| 인자 | `문자열`: 따옴표로 감쌀 내용 |

#### 사용 예시

```bash
echo "3 * 4 = 12"
name=나가수
echo '내 이름은 $name 현재 시간은 $(date)'
echo "내 이름은 $name 현재 시간은 $(date)"
```

작은따옴표 안의 `$name`과 `$(date)`는 그대로 출력되고, 큰따옴표 안에서는 값과 실행 결과로 바뀐다.
따옴표가 중첩되면 바깥쪽 따옴표가 적용된다.

---

### 명령어 표기 형식

- `[옵션]`: 선택적으로 입력하는 옵션
- `%작업번호`: `jobs`에서 확인한 작업 번호 앞에 `%`를 붙인 형태
- `명령어`, `파일`, `단어`: 실제 명령어나 파일명, 구분자로 바꿔 입력하는 자리표시자
- 대괄호(`[ ]`)는 선택 항목을 설명할 때 사용하는 표기이며, 파일 이름 패턴의 `[ac]`처럼 실제로 입력하는 경우와 구분한다.
