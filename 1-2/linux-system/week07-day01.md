## 배운 명령어

### 1. `ls`로 i-노드와 링크 확인

| 항목 | 내용 |
| --- | --- |
| 명령어 | `ls [옵션] 파일...` |
| 기능 | 파일의 i-노드 번호, 접근권한, 하드 링크 수 등을 확인한다. |
| 옵션 | `-i`: i-노드 번호 출력<br>`-l`: 파일 정보를 자세히 출력 |
| 인자 | `파일`: 정보를 확인할 파일 또는 링크 |

#### 사용 예시

```bash
ls -i cs1.txt
ls -li file1 file2
ls -li file1 link1
ls -l link1
```

파일 이름은 디렉터리 엔트리에 저장되고, i-노드는 파일의 메타데이터와 데이터 블록 위치를 관리한다. 같은 파일 시스템에서 `file1`과 `file2`가 동일한 i-노드 번호를 가지면 같은 파일을 가리키는 하드 링크이다.

심볼릭 링크는 별도의 i-노드를 가지며, `ls -l`로 확인하면 `link1 -> file1`처럼 대상 경로가 표시된다.

### 2. `stat`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `stat 파일...` |
| 기능 | 파일의 i-노드 번호, 크기, 링크 수, 권한, 시간 정보 등을 자세히 출력한다. |
| 옵션 | 자료의 예시에서는 사용하지 않음 |
| 인자 | `파일`: 상세 정보를 확인할 파일 |

#### 사용 예시

```bash
stat file1
```

| 출력 항목 | 의미 |
| --- | --- |
| File | 파일 이름 |
| Size | 파일의 크기(바이트) |
| Blocks | 할당된 공간을 나타내는 블록 수 |
| Inode | i-노드 번호 |
| Links | 하드 링크 수 |
| Access | 접근권한 또는 마지막 접근 시간. 출력 위치에 따라 구분 |
| Modify | 파일 내용의 마지막 수정 시간 |
| Change | 파일 상태 정보의 마지막 변경 시간 |

자료의 `stat` 예시에서 `Blocks`는 512바이트 단위이다. 파일 시스템의 데이터 블록 크기와 구분한다.

### 3. `ln`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `ln [-s] 원본파일 링크명` |
| 기능 | 파일에 대한 하드 링크 또는 심볼릭 링크를 생성한다. |
| 옵션 | 생략: 하드 링크 생성<br>`-s`: 심볼릭 링크 생성 |
| 인자 | `원본파일`: 링크가 가리킬 파일<br>`링크명`: 새로 만들 링크의 이름 |

#### 사용 예시

```bash
# 예시에 사용할 파일 생성
echo "Hello" > file1
ls -li file1

# 하드 링크 생성 후 i-노드 번호와 링크 수 확인
ln file1 file2
ls -li file1 file2

# 심볼릭 링크 생성 후 대상 경로 확인
ln -s file1 link1
ls -li file1 link1
cat link1
```

`echo`는 문자열을 출력하고 `>`는 그 출력을 파일에 저장한다. `cat link1`은 심볼릭 링크가 가리키는 `file1`의 내용을 출력한다.

| 구분 | 하드 링크 | 심볼릭 링크 |
| --- | --- | --- |
| i-노드 | 원본과 동일 | 원본과 별도 |
| 저장 관계 | 같은 파일의 데이터 공유 | 대상의 경로 문자열 저장 |
| 생성 범위 | 같은 파일 시스템 안에서 생성 | 다른 파일 시스템의 대상도 지정 가능 |
| 원본 이름 삭제 시 | 다른 하드 링크로 계속 접근 가능 | 대상 경로가 사라지면 깨진 링크가 됨 |

```bash
# 위 예시에서 만든 file1을 삭제한 뒤 비교
rm file1
cat file2
ls -l link1
```

`rm file1`은 해당 파일 이름을 제거한다. `file2`라는 하드 링크가 남아 있으므로 파일 내용은 계속 읽을 수 있지만, `file1`을 가리키는 `link1`은 깨진 링크가 된다. `ls -l link1`로 링크 자체와 저장된 대상 경로는 확인할 수 있다.

### 4. `df`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `df [파일...]` |
| 기능 | 마운트된 파일 시스템의 전체 공간, 사용량, 가용 공간 등을 출력한다. |
| 옵션 | 자료의 예시에서는 사용하지 않음 |
| 인자 | `파일`: 해당 파일이나 디렉터리가 속한 파일 시스템을 확인. 생략하면 마운트된 파일 시스템 정보를 출력 |

#### 사용 예시

```bash
df
df /
```

| 출력 항목 | 의미 |
| --- | --- |
| 파일 시스템 | 장치명 또는 파일 시스템 이름 |
| 1K-블록 | 전체 공간을 1KiB 단위로 표시한 값 |
| 사용 | 사용 중인 공간 |
| 가용 | 사용할 수 있는 공간 |
| 사용% | 공간 사용률 |
| 마운트위치 | 파일 시스템이 연결된 디렉터리 |

자료의 출력은 1K-블록 단위이며, `df /`는 루트 디렉터리가 속한 파일 시스템의 사용 정보를 보여준다.

### 5. `mount`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `mount [옵션] 장치명 디렉터리` |
| 기능 | 장치의 파일 시스템을 지정한 디렉터리에 연결하여 접근할 수 있게 한다. |
| 옵션 | `-o ro`: 읽기 전용으로 마운트<br>`-o rw`: 읽기·쓰기 가능하게 마운트<br>`-o remount`: 기존 마운트의 옵션 변경을 위해 다시 마운트 |
| 인자 | `장치명`: 연결할 장치 파일<br>`디렉터리`: 마운트 지점 |

#### 사용 예시

```bash
# 관리자 권한으로 실행하는 예시
mount /dev/sr0 /mnt
ls /mnt
```

자료에서는 CD-ROM 장치인 `/dev/sr0`을 `/mnt`에 연결한다. 실제 장치명과 마운트 지점은 사용 환경에 맞게 지정한다.

`/etc/fstab`에는 파일 시스템의 마운트 설정을 기록한다. 각 줄의 필드는 다음 순서로 작성한다.

```text
<file system> <mount point> <type> <options> <dump> <pass>
/dev/disk/by-uuid/d2f11711-... / ext4 defaults 0 1
```

| 필드 | 의미 |
| --- | --- |
| file system | 장치 경로나 파일 시스템 식별자 |
| mount point | 마운트할 디렉터리 |
| type | `ext4`, `ntfs` 등의 파일 시스템 유형 |
| options | 읽기·쓰기, 자동 마운트 등의 옵션 |
| dump | `dump` 백업 대상 여부. 보통 `0` 사용 |
| pass | 부팅 시 `fsck` 검사 순서. `0`이면 검사하지 않음 |

예시의 UUID는 일부가 생략된 표기이다. `mount`로 수행한 임시 마운트가 `/etc/fstab`에 자동으로 추가되는 것은 아니다.

### 8. `find`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `find 디렉터리 [검색조건] [처리방법]` |
| 기능 | 지정한 디렉터리 아래에서 파일 이름이나 속성에 맞는 파일을 찾아 출력하거나 처리한다. |
| 옵션 | `-name 패턴`: 파일 이름으로 검색<br>`-user 사용자명`: 소유자로 검색<br>`-group 그룹명`: 소유 그룹으로 검색<br>`-size n`: 파일 크기로 검색<br>`-type 종류`: 파일 종류로 검색<br>`-perm 모드`: 접근권한이 정확히 일치하는 파일 검색<br>`-links n`: 하드 링크 수로 검색<br>`-atime n`: 마지막 접근 시간으로 검색<br>`-mtime n`: 마지막 내용 수정 시간으로 검색<br>`-print`: 찾은 경로 출력<br>`-ls`: 찾은 파일의 상세 정보 출력<br>`-exec 명령어 {} \;`: 찾은 파일마다 명령어 실행 |
| 인자 | `디렉터리`: 검색 시작 위치<br>`패턴`, `사용자명`, `그룹명`, `n`, `모드`, `종류`: 검색 조건에 사용할 값 |

#### 사용 예시

```bash
# 파일 이름으로 검색
find ~ -name src -print
find ~ -name src -ls
find /usr -name '*.c' -print
```

`~`는 사용자의 홈 디렉터리이다. `*.c`는 쉘에서 먼저 파일 이름으로 확장되지 않도록 따옴표로 감싼다. `-print`는 검색 시작 위치에 따른 경로를 출력하므로, `find .`의 결과가 항상 절대 경로인 것은 아니다.

```bash
# 소유자, 크기, 종류, 권한으로 검색
find . -user chang -print
find . -size +1024 -print
find ~ -type d -print
find . -perm 700 -ls

# 접근 시간과 수정 시간으로 검색
find . -atime +30 -print
find . -mtime -7 -print

# 여러 조건을 함께 적용
find . -type d -perm 700 -print
find . -name core -size +2048 -ls
```

| `-type` 값 | 파일 종류 |
| --- | --- |
| `d` | 디렉터리 |
| `f` | 일반 파일 |
| `l` | 심볼릭 링크 |
| `b` | 블록 장치 파일 |
| `c` | 문자 장치 파일 |
| `s` | 소켓 파일 |

크기 단위를 생략한 `-size`는 파일 크기를 512바이트 단위로 올림하여 비교한다. `+n`은 `n`보다 큼, `-n`은 `n`보다 작음, `n`은 정확히 일치함을 뜻한다. `-size +1024`는 512KiB보다 큰 파일을 찾는다. [GNU find 크기 조건](https://www.gnu.org/software/findutils/manual/html_node/find_html/Size.html)

`-atime`과 `-mtime`은 경과 시간을 24시간 단위로 내림하여 비교한다. 따라서 `-atime +30`은 마지막 접근 후 31일 이상 지난 파일, `-mtime -7`은 마지막 내용 수정 후 7일 미만인 파일을 찾는다. 조건을 나란히 쓰면 모두 만족해야 한다. [GNU find 시간 조건](https://www.gnu.org/software/findutils/manual/html_node/find_html/Age-Ranges.html)

```bash
# 찾은 core 파일마다 삭제 여부를 확인
find . -name core -exec rm -i {} \;

# 마지막 접근 후 31일 이상 지난 C 소스 파일의 상세 정보 출력
find . -name '*.c' -atime +30 -exec ls -l {} \;
```

`{}`는 찾은 파일의 경로로 대체되고, `\;`는 `-exec`로 실행할 명령어의 끝을 나타낸다. `rm -i`는 각 파일을 삭제하기 전에 확인을 요청한다.

### 9. `grep`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `grep [옵션] 패턴 [파일...]` |
| 기능 | 파일이나 표준입력에서 패턴과 일치하는 줄을 찾아 출력한다. |
| 옵션 | `-i`: 대소문자 구분 없이 검색<br>`-l`: 일치하는 줄이 있는 파일의 이름만 출력<br>`-n`: 줄 번호를 함께 출력<br>`-v`: 패턴과 일치하지 않는 줄 선택<br>`-c`: 선택된 줄 수 출력<br>`-w`: 단어 전체가 일치하는 경우 선택 |
| 인자 | `패턴`: 검색할 문자열 또는 정규식<br>`파일`: 검색 대상. 생략하면 표준입력 사용 |

#### 사용 예시

```bash
grep with you.txt
grep -w with you.txt
grep -n with you.txt
grep -i when you.txt
grep -v raise you.txt
```

`grep with you.txt`는 `without`처럼 `with`가 일부로 포함된 단어도 찾는다. `-w`를 사용하면 `with`가 독립된 단어로 일치하는 줄을 선택한다. `-c`는 일치한 문자열의 총개수가 아닌 선택된 줄 수를 출력한다.

| 정규식 | 의미 | 예시 |
| --- | --- | --- |
| `.` | 임의의 한 문자 | `a...b`: `a`와 `b` 사이에 문자 3개 |
| `*` | 바로 앞 요소를 0번 이상 반복 | `a*b`: `b`, `ab`, `aab` 등 |
| `[abc]` | 괄호 안 문자 중 하나 | `[abc]d`: `ad`, `bd`, `cd` |
| `[a-z]` | 지정 범위의 문자 중 하나 | 소문자 범위의 문자 |
| `[^abc]` | 괄호 안 문자를 제외한 문자 하나 | `[^abc]d`: `ed`, `fd` 등 |
| `^` | 줄의 시작 | `^문자열`: 해당 문자열로 시작하는 줄 |
| `$` | 줄의 끝 | `문자열$`: 해당 문자열로 끝나는 줄 |

```bash
grep 'st..' you.txt
grep 'st.*e' you.txt
grep -w 'st.*e' you.txt
```

`st..`는 `st` 뒤에 문자 2개가 이어지는 부분을 찾고, `st.*e`는 `st`와 뒤의 `e` 사이에 문자가 0개 이상 있는 부분을 찾는다.

```bash
ls -l | grep chang
ps -ef | grep chang
```

파이프(`|`)를 사용하면 앞 명령어의 출력에서 원하는 패턴이 있는 줄을 선택할 수 있다.

### 10. `sort`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `sort [옵션] [파일...]` |
| 기능 | 텍스트 파일이나 표준입력의 내용을 줄 단위로 정렬한다. |
| 옵션 | `-b`: 정렬 키의 앞쪽 공백 무시<br>`-c`: 정렬 여부 검사<br>`-d`: 문자·숫자·공백을 기준으로 사전식 비교<br>`-f`: 대소문자 구분 없이 비교<br>`-n`: 숫자 값으로 비교<br>`-r`: 역순으로 정렬<br>`-t 문자`: 필드 구분자 지정<br>`-k 시작[,끝]`: 정렬 키의 필드 범위 지정<br>`-o 출력파일`: 정렬 결과를 파일에 저장 |
| 인자 | `파일`: 정렬할 파일. 생략하면 표준입력 사용<br>`시작`, `끝`: 1부터 시작하는 필드 번호 |

#### 사용 예시

```bash
sort you.txt
sort -r you.txt
sort -o sort.txt you.txt
```

기본적으로 줄 전체를 비교하여 오름차순으로 정렬하며, `-r`은 그 역순으로 정렬한다. 문자 비교 순서는 실행 환경의 로캘에 영향을 받는다.

```bash
# 세 번째 필드부터 줄 끝까지를 정렬 키로 사용
sort -k 3 you.txt

# 세 번째 필드만 정렬 키로 사용
sort -k 3,3 you.txt

# 콜론으로 필드를 나누고 세 번째 필드를 숫자로 비교
sort -t: -k 3,3 -n /etc/passwd
```

`-k 3`과 `-k 3,3`은 정렬 키의 범위가 다르다. 자료에서는 두 형식을 함께 소개하지만, 세 번째 필드만 지정하려면 `-k 3,3`을 사용한다. `/etc/passwd`의 세 번째 필드는 UID이다. [GNU sort 매뉴얼](https://www.gnu.org/software/coreutils/manual/html_node/sort-invocation.html)

`-n`은 `49`와 `100` 같은 문자열을 숫자 값으로 비교한다. `-c`는 정렬 결과를 출력하는 대신 입력이 정렬되어 있는지 검사한다.

자료의 `+시작필드 -종료필드`는 필드 번호를 0부터 세는 구식 표기이다. 예를 들어 `+2 -3`에 해당하는 범위는 현재 표기의 `-k 3,3`으로 작성한다.

### 11. `cmp`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `cmp 파일1 파일2` |
| 기능 | 두 파일을 바이트 단위로 비교한다. |
| 옵션 | 자료의 예시에서는 사용하지 않음 |
| 인자 | `파일1`, `파일2`: 비교할 두 파일 |

#### 사용 예시

```bash
cmp you.txt me.txt
```

두 파일이 같으면 아무것도 출력하지 않는다. 내용이 다르면 처음 다른 바이트 위치와 줄 번호를 출력하며, 한 파일이 다른 파일의 앞부분과 같고 먼저 끝나면 파일 끝에 도달했음을 알린다.

### 12. `diff`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `diff [-i] 파일1 파일2` |
| 기능 | 두 파일을 줄 단위로 비교하여 차이를 출력한다. |
| 옵션 | `-i`: 대소문자 차이를 무시하여 비교 |
| 인자 | `파일1`, `파일2`: 비교할 두 파일 |

#### 사용 예시

```bash
diff you.txt me.txt
diff me.txt you.txt
diff -i you.txt me.txt
```

기본 출력은 첫 번째 파일을 두 번째 파일과 같게 만들기 위해 필요한 추가·삭제·변경을 나타낸다. 두 파일이 같으면 아무것도 출력하지 않는다.

| 출력 표기 | 의미 |
| --- | --- |
| `n1a n3,n4` | 첫 번째 파일의 `n1`행 뒤에 두 번째 파일의 `n3`~`n4`행 추가 |
| `n1,n2d n3` | 첫 번째 파일의 `n1`~`n2`행 삭제. 두 번째 파일의 `n3`행 뒤 위치에 해당 |
| `n1,n2c n3,n4` | 첫 번째 파일의 `n1`~`n2`행을 두 번째 파일의 `n3`~`n4`행으로 변경 |
| `<` | 첫 번째 파일의 내용 |
| `>` | 두 번째 파일의 내용 |
| `---` | 변경 출력에서 두 파일의 내용을 구분하는 줄 |

실제 줄 번호 표기에는 `9a10,13`, `10,13d9`, `1c1`처럼 공백이 없다. `9a10,13`은 첫 번째 파일의 9행 뒤에 두 번째 파일의 10~13행을 추가하라는 뜻이다.

```text
1c1
< This is the first file
---
> This is the second file.
```

이 예시는 첫 번째 파일의 1행을 두 번째 파일의 1행으로 변경해야 한다는 의미이다.

### 명령어 표기 형식

- `[옵션]`, `[파일]`: 선택적으로 입력하는 항목
- `파일...`: 하나 이상의 파일을 지정할 수 있음을 나타내는 표기
- `파일`, `파일1`, `파일2`, `원본파일`, `링크명`, `디렉터리`: 실제 파일명이나 경로로 바꿔 입력하는 자리표시자
- `you.txt`, `me.txt`, `cs1.txt`, `chang`: 자료에서 사용한 파일명과 사용자명
- `~`: 현재 사용자의 홈 디렉터리
- `.`: 현재 디렉터리
- `장치명`: `/dev/sr0` 등의 장치 파일 경로
- `|`: 앞 명령어의 표준출력을 뒤 명령어의 표준입력으로 전달하는 파이프
- `find`의 `{}`와 `\;`: 찾은 파일의 경로와 `-exec` 명령어의 끝을 나타내는 기호
- 자료의 `$`, `#`: 각각 일반 사용자와 관리자 쉘의 프롬프트 표시. 명령어에 포함하여 입력하지 않음
