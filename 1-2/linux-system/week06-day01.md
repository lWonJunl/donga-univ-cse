## 배운 명령어

### 1. `ps`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `ps [옵션]` |
| 기능 | 프로세스의 실행 상태를 출력한다. |
| 옵션 | `-f`: 자세한 형식으로 출력<br>`-e`: 모든 프로세스를 출력 |
| 인자 | 자료의 예시에서는 사용하지 않음 |

#### 사용 예시

```bash
ps
ps -f
ps -ef | more
```

`ps`는 기본적으로 현재 사용자와 같은 유효 사용자 ID를 가지며 현재 터미널에 연결된 프로세스를 보여준다. `ps -ef`는 모든 프로세스를 자세히 출력한다.

| 출력 항목 | 의미 |
| --- | --- |
| UID | 프로세스의 사용자 ID |
| PID | 프로세스 번호 |
| PPID | 부모 프로세스 번호 |
| C | CPU 사용률과 관련된 값 |
| STIME | 프로세스의 시작 시간 |
| TTY | 프로세스가 연결된 터미널 |
| TIME | 프로세스가 사용한 CPU 시간 |
| CMD | 실행 중인 명령어 |

### 2. `grep`

| --- | --- |

| 인자 | `패턴`: 검색할 문자열 |

#### 사용 예시


### 3. `pgrep`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `pgrep [옵션] 패턴` |
| 기능 | 패턴과 일치하는 프로세스의 PID를 출력한다. |
| 옵션 | `-l`: PID와 프로세스 이름을 함께 출력<br>`-f`: 프로세스 이름 대신 전체 명령줄을 대상으로 검색<br>`-n`: 일치하는 프로세스 중 가장 최근에 시작한 프로세스만 선택<br>`-x`: 이름이 패턴과 정확하게 일치하는 프로세스만 선택 |
| 인자 | `패턴`: 찾을 프로세스의 이름 또는 명령줄 패턴 |

#### 사용 예시

```bash
pgrep sshd
pgrep -l sshd
pgrep -ln sshd
```

자료의 `-f` 설명은 전체 명령줄을 대상으로 검색한다는 의미로 정리했다. `-f`만으로 명령어 경로를 출력하는 것은 아니다. [pgrep 매뉴얼](https://man7.org/linux/man-pages/man1/pgrep.1.html)

### 4. `명령어 &`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `명령어 &` |
| 기능 | 명령어를 후면에서 실행하여 쉘에서 다른 작업을 계속할 수 있게 한다. |
| 옵션 | `&`: 명령어 끝에 붙이는 후면 실행 기호 |
| 인자 | `명령어`: 후면에서 실행할 명령어 또는 명령어 그룹 |

#### 사용 예시

```bash
sleep 10 &
ps
```

후면 작업을 시작하면 `[작업번호] 프로세스번호`가 표시된다. 전면 실행에서는 쉘이 명령어의 종료를 기다리지만 후면 실행에서는 기다리지 않는다.

### 5. `sleep`

### 6. `Ctrl+C`, `Ctrl+Z`

| 항목 | 내용 |
| --- | --- |
| 명령어 | 전면 작업 실행 중 `Ctrl+C` 또는 `Ctrl+Z` 입력 |
| 기능 | `Ctrl+C`는 전면 작업에 종료 요청을 보내고, `Ctrl+Z`는 전면 작업을 일시 정지시킨다. |
| 옵션 | `Ctrl+C`: `SIGINT` 전달<br>`Ctrl+Z`: `SIGTSTP` 전달 |
| 인자 | 없음 |

#### 사용 예시

```bash
# 실행 중 Ctrl+C를 눌러 종료 요청
(sleep 100; echo DONE)

# 실행 중 Ctrl+Z를 눌러 일시 정지
(sleep 100; echo DONE)
```

자료에서 `^C`, `^Z`는 해당 키를 눌렀음을 나타내는 표기이다. `Ctrl+Z`로 정지한 작업은 `fg` 또는 `bg`로 다시 실행할 수 있다.

### 7. `fg`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `fg [%작업번호]` |
| 기능 | 정지되었거나 후면에서 실행 중인 작업을 전면에서 실행한다. |
| 옵션 | 자료의 예시에서는 사용하지 않음 |
| 인자 | `%작업번호`: 전면으로 가져올 작업 번호. 생략하면 현재 작업을 선택 |

#### 사용 예시

```bash
# 실행 중 Ctrl+Z를 누른 뒤 fg로 재개
(sleep 100; echo DONE)
fg

# 후면에서 실행한 작업을 전면으로 전환
(sleep 100; echo DONE) &
fg %1
```

### 9. 후면 작업의 입출력 (`>`, `<`, `|`)

| 항목 | 내용 |
| --- | --- |
| 명령어 | `명령어 > 출력파일 &`<br>`명령어 < 입력파일 &`<br>`명령어1 \| 명령어2 &` |
| 기능 | 후면 작업의 출력을 파일이나 다른 명령어로 전달하고, 입력은 파일에서 받는다. |
| 옵션 | `>`: 표준출력 재지정<br>`<`: 표준입력 재지정<br>`\|`: 파이프<br>`&`: 후면 실행 |
| 인자 | `출력파일`: 결과를 저장할 파일<br>`입력파일`: 입력으로 사용할 파일 |

#### 사용 예시

```bash
find . -name test.c -print > find.txt &
find . -name test.c -print | mail chang &

# 명령어와 파일명은 실행할 작업에 맞게 지정
명령어 < 입력파일 &
```

자료에서는 `find`로 찾은 경로를 `find.txt`에 저장하거나, `mail chang`의 입력으로 전달하여 `chang` 사용자에게 보낸다.

### 10. `kill`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `kill [-시그널] 프로세스번호`<br>`kill [-시그널] %작업번호`<br>`kill -l` |
| 기능 | 지정한 프로세스나 작업에 시그널을 보내 종료·정지·재개를 요청한다. |
| 옵션 | 생략: `SIGTERM`으로 종료 요청<br>`-9`, `-KILL`: `SIGKILL`로 강제 종료<br>`-STOP`: 실행 정지<br>`-CONT`: 정지한 프로세스 재개<br>`-l`: 시그널 목록 출력 |
| 인자 | `프로세스번호`: 대상 PID<br>`%작업번호`: 현재 쉘의 대상 작업 번호 |

#### 사용 예시

```bash
(sleep 100; echo done) &

# 표시된 PID가 8320일 때 아래 두 방식 중 하나 사용
kill 8320
kill %1

# 시그널 목록 확인
kill -l

# 각각 대상 프로세스가 실행 중일 때 사용하는 예시
kill -9 프로세스번호
kill -KILL 프로세스번호
kill -STOP 프로세스번호
kill -CONT 프로세스번호
```

`SIGTERM`은 종료 요청이며 프로세스가 처리할 수 있다. `SIGKILL`은 프로세스가 잡거나 무시할 수 없는 강제 종료 시그널이다. PID와 작업 번호는 실행할 때 확인한 값으로 바꿔 입력한다.

### 12. `wait`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `wait [프로세스번호]` |
| 기능 | 지정한 자식 프로세스가 종료될 때까지 기다린다. 번호를 생략하면 현재 쉘의 모든 후면 작업이 끝나기를 기다린다. |
| 옵션 | 자료의 예시에서는 사용하지 않음 |
| 인자 | `프로세스번호`: 기다릴 자식 프로세스의 PID |

#### 사용 예시

```bash
(sleep 10; echo 1번 끝) &

# 표시된 PID가 1231인 경우
echo 2번 끝; wait 1231; echo 3번 끝
```

`2번 끝`을 출력한 뒤 자식 프로세스를 기다리므로 `1번 끝` 다음에 `3번 끝`이 출력된다.

```bash
(sleep 10; echo 1번 끝) &
(sleep 10; echo 2번 끝) &
echo 3번 끝; wait; echo 4번 끝
```

두 후면 작업이 모두 끝난 뒤 `4번 끝`을 출력한다. 두 작업 사이의 완료 순서는 실행 상황에 따라 달라질 수 있다.

### 13. `nohup`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `nohup 명령어 [인수] &` |
| 기능 | 연결 끊김 시그널인 `SIGHUP`을 무시하도록 명령어를 실행한다. 자료에서는 로그아웃 후에도 후면 작업을 계속하는 데 사용한다. |
| 옵션 | `&`: 명령어를 후면에서 실행하는 쉘 기호 |
| 인자 | `명령어`, `인수`: 실행할 명령어와 전달할 값 |

#### 사용 예시

```bash
nohup find / -name '*.c' -print &
nohup find / -name '*.c' -print > filename &
```

표준출력이 터미널이면 보통 `nohup.out`에 저장한다. `>`로 출력 파일을 직접 지정할 수도 있다. `*.c`는 현재 디렉터리의 파일 이름으로 먼저 대치되지 않도록 따옴표로 감쌌다.

### 14. `nice`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `nice`<br>`nice [-n 조정수치] 명령어 [인수]` |
| 기능 | 현재 nice 값을 확인하거나, nice 값을 조정하여 명령어를 실행한다. |
| 옵션 | `-n 조정수치`: 현재 nice 값에 더할 값 지정 |
| 인자 | `명령어`, `인수`: 조정된 nice 값으로 실행할 명령어와 인수 |

#### 사용 예시

```bash
nice
nice -n 10 ps -ef
```

nice 값은 `-20`부터 `19`까지이며, 값이 클수록 CPU 스케줄링 우선순위가 낮아진다. 기본값이 `0`인 경우 `-n 10`으로 실행하면 nice 값이 `10`이 된다.

### 15. `renice`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `renice [-n] 우선순위 [-g \| -u \| -p] 대상` |
| 기능 | 이미 실행 중인 프로세스의 nice 값을 변경한다. |
| 옵션 | `-n`: 변경할 nice 값 지정<br>`-g`: 프로세스 그룹 ID로 대상 지정<br>`-u`: 사용자 이름 또는 UID로 대상 지정<br>`-p`: PID로 대상 지정 |
| 인자 | `우선순위`: 변경할 nice 값<br>`대상`: PID, 프로세스 그룹 ID 또는 사용자 |

#### 사용 예시

```bash
# 프로세스번호는 변경할 PID로 대체
renice -n 10 -p 프로세스번호
```

`nice -n`은 새 명령어에 적용할 조정량을 지정하고, `renice -n`은 실행 중인 프로세스의 목표 nice 값을 지정한다.

### 17. `ls`로 특수 실행권한 확인

| 항목 | 내용 |
| --- | --- |
| 명령어 | `ls -l 파일` |
| 기능 | 파일의 권한과 소유자·그룹을 확인한다. 자료에서는 set-user-id와 set-group-id 실행파일을 확인하는 데 사용한다. |
| 옵션 | `-l`: 파일 정보를 자세히 출력 |
| 인자 | `파일`: 권한을 확인할 실행파일 |

#### 사용 예시

```bash
ls -l /bin/sudo
ls -l /bin/passwd
ls -l /bin/crontab
```

사용자 실행권한 자리에 표시되는 `s`는 set-user-id, 그룹 실행권한 자리에 표시되는 `s`는 set-group-id를 나타낸다. set-user-id 실행파일은 실행할 때 파일 소유자의 유효 사용자 ID를, set-group-id 실행파일은 파일 소유 그룹의 유효 그룹 ID를 갖게 한다.

자료에서는 `passwd`가 set-user-id 권한을 통해 root 권한으로 `/etc/shadow`를 수정하는 과정을 설명한다.

### 18. `chmod`로 특수 실행권한 설정

| 항목 | 내용 |
| --- | --- |
| 명령어 | `chmod 모드 파일` |
| 기능 | 파일에 set-user-id 또는 set-group-id 권한을 설정한다. |
| 옵션 | 자료의 예시에서는 사용하지 않음 |
| 인자 | `4755`: set-user-id와 `755` 권한 설정<br>`2755`: set-group-id와 `755` 권한 설정<br>`u+s`: set-user-id 추가<br>`g+s`: set-group-id 추가<br>`파일`: 권한을 변경할 파일 |

#### 사용 예시

```bash
# set-user-id 설정: 두 방식 중 하나 사용
chmod 4755 파일
chmod u+s 파일

# set-group-id 설정: 두 방식 중 하나 사용
chmod 2755 파일
chmod g+s 파일
```

숫자 모드는 일반 권한도 함께 설정하고, `u+s`와 `g+s`는 기존 권한에 해당 특수 권한을 추가한다.

### 19. `crontab`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `crontab 파일`<br>`crontab -l`<br>`crontab -e`<br>`crontab -r` |
| 기능 | 주기적으로 실행할 명령어를 등록하거나, 등록된 예약을 확인·수정·삭제한다. |
| 옵션 | `-l`: 등록된 예약 목록 출력<br>`-e`: 예약 편집 또는 생성<br>`-r`: 현재 사용자의 예약 전체 삭제 |
| 인자 | `파일`: 실행 시각과 명령어를 작성한 crontab 파일 |

#### 사용 예시

```bash
crontab chang.cron
crontab -l
crontab -e

# 등록된 예약 전체를 삭제하는 경우
crontab -r
```

사용자 crontab의 한 줄은 `분 시 일 월 요일 명령어`로 작성한다. `/etc/crontab` 등 시스템 crontab에는 명령어 앞에 사용자 필드가 추가된다. 자료의 `[사용자]` 필드는 이 차이를 구분하여 읽는다. [crontab 파일 형식 매뉴얼](https://man7.org/linux/man-pages/man5/crontab.5.html)

```text
# chang.cron: 매일 18시 30분에 지정 경로의 파일 삭제
30 18 * * * rm /home/chang/tmp/*

# 매시간 정각에 메시지 추가
0 * * * * echo "뻐꾹" >> /tmp/x

# 시스템 crontab 예시: root 사용자로 매일 1시 20분에 실행
20 1 * * * root find /tmp -atime +3 -exec rm -f {} \;

# 짝수 달의 수요일~금요일 1시 30분에 전체 사용자에게 메시지 전달
30 1 * 2,4,6,8,10,12 3-5 /usr/bin/wall /var/tmp/message
```

`*`는 해당 시간 필드의 모든 값을 뜻한다. `2,4,6,8,10,12`는 월 목록, `3-5`는 수요일부터 금요일까지의 범위이다. `wall`은 지정한 메시지를 로그인한 사용자들에게 전달한다.

다른 사용자를 지정할 때 Linux의 `crontab`은 `crontab -u 사용자명 -l`처럼 `-u`를 사용한다. 자료의 `crontab -l [사용자]` 표기는 이 형태로 확인한다. [crontab 명령어 매뉴얼](https://man7.org/linux/man-pages/man1/crontab.1.html)

### 20. `at`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `at [-f 파일] 시간`<br>`at -r 작업번호` |
| 기능 | 지정한 시각에 명령어를 한 번 실행하도록 예약하거나, 예약된 작업을 제거한다. |
| 옵션 | `-f 파일`: 실행할 명령어를 파일에서 읽음<br>`-r`: 지정한 예약 작업 제거 |
| 인자 | `시간`: 실행할 시각과 날짜<br>`작업번호`: 제거할 예약 작업 번호 |

#### 사용 예시

```bash
at 1145 jan 31
# at> 프롬프트에서 아래 명령어를 입력한 뒤 Ctrl+D로 종료
sort infile > outfile
```

1월 31일 11시 45분에 `sort infile > outfile`을 실행하도록 등록하는 예시이다. 자료의 `<EOT>`는 `Ctrl+D`로 입력을 끝내는 것을 나타낸다.

```bash
at -f 파일 시간
at -r 작업번호
```

`작업번호`는 `atq`로 확인한 예약 번호로 바꿔 입력한다.

---

### 21. `atq`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `atq` |
| 기능 | `at`에 등록되어 실행을 기다리는 예약 작업을 출력한다. |
| 옵션 | 자료의 예시에서는 사용하지 않음 |
| 인자 | 없음 |

#### 사용 예시

```bash
atq
```

출력에서 예약 작업 번호와 실행 시각 등을 확인하고, 취소할 작업은 `at -r 작업번호`로 제거한다.

---

### 명령어 표기 형식

- `[옵션]`, `[인수]`: 선택적으로 입력하는 항목
- `프로세스번호`: `ps`, `pgrep` 또는 후면 실행 시 확인한 PID
- `%작업번호`: 현재 쉘의 작업 번호 앞에 `%`를 붙인 형태. PID와 구분한다.
- `at`의 `작업번호`: 예약 작업을 식별하는 번호. 쉘의 `%작업번호`와 구분한다.
- `명령어`, `파일`, `입력파일`, `시간`: 실제 명령어나 파일명, 시각으로 바꿔 입력하는 자리표시자
- `Ctrl+C`, `Ctrl+Z`, `Ctrl+D`: 해당 키 조합을 누르는 동작
