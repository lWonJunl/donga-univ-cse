## 배운 명령어

### 1. `cp`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `cp [-i] 파일1 파일2`<br>`cp 파일 디렉터리`<br>`cp [-r] 디렉터리1 디렉터리2` |
| 기능 | 파일을 다른 이름이나 디렉터리에 복사한다. `-r` 옵션을 사용하면 하위 디렉터리를 포함해 디렉터리 전체를 복사한다. |
| 옵션 | `-i`: 대상 파일이 이미 있으면 덮어쓸지 확인<br>`-r`: 하위 디렉터리를 포함해 재귀적으로 복사 |
| 인자 | `파일1`, `파일2`: 복사할 원본과 대상 파일<br>`디렉터리`: 파일을 복사할 대상 디렉터리 |

#### 사용 예시

```bash
# 파일을 다른 이름으로 복사
cp cs1.txt cs2.txt

# 여러 파일을 /tmp 디렉터리로 복사
cp cs1.txt cs2.txt /tmp

# 디렉터리 전체를 복사
cp -r test temp
```

`cp -i`를 사용하면 대상과 같은 이름의 파일이 있을 때 덮어쓰기를 확인하므로 안전하게 복사할 수 있다.

### 2. `mv`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `mv [-i] 파일1 파일2`<br>`mv 파일 디렉터리`<br>`mv 디렉터리1 디렉터리2` |
| 기능 | 파일이나 디렉터리의 이름을 변경하거나, 지정한 디렉터리로 이동한다. |
| 옵션 | `-i`: 대상과 같은 이름의 파일이 있으면 덮어쓸지 확인 |
| 인자 | `파일1`, `파일2`: 이름을 바꾸거나 이동할 파일과 대상 이름<br>`디렉터리`: 이동할 대상 디렉터리 |

#### 사용 예시

```bash
# 파일 이름 변경
mv cs2.txt cs3.txt

# 파일을 /tmp 디렉터리로 이동
mv cs3.txt /tmp

# 디렉터리 이름 변경
mv temp tmp
```

여러 파일을 디렉터리로 이동할 수도 있다.

```bash
mv cs1.txt cs3.txt /tmp
```

### 3. `rm`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `rm [-i] 파일+`<br>`rm [-ri] 디렉터리` |
| 기능 | 파일을 삭제한다. `-r` 옵션을 사용하면 디렉터리와 그 아래의 파일 및 하위 디렉터리를 모두 삭제한다. |
| 옵션 | `-i`: 삭제하기 전에 확인<br>`-r`: 디렉터리 아래 내용을 재귀적으로 삭제 |
| 인자 | `파일`: 삭제할 하나 이상의 파일<br>`디렉터리`: 삭제할 디렉터리 |

#### 사용 예시

```bash
# 파일 삭제
rm cs1.txt
rm cs1.txt cs3.txt

# 삭제 전 확인
rm -i cs1.txt

# 디렉터리 전체를 확인하면서 삭제
rm -ri test
```

`rm`으로 삭제한 파일은 휴지통으로 이동하지 않으므로 대상과 옵션을 확인해야 한다.

### 4. `ln`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `ln [-s] 파일1 파일2`<br>`ln [-s] 파일1 디렉터리` |
| 기능 | 기존 파일에 접근할 수 있는 새 이름인 링크를 만든다. |
| 옵션 | `-s`: 심볼릭 링크 생성 |
| 인자 | `파일1`: 원본 파일<br>`파일2`: 새 링크 이름<br>`디렉터리`: 링크를 만들 대상 디렉터리 |

#### 사용 예시

```bash
# 하드 링크 만들기
ln hello.txt hi.txt

# 심볼릭 링크 만들기
ln -s hello.txt hi.txt

# /usr/bin/gcc를 가리키는 심볼릭 링크 만들기
ln -s /usr/bin/gcc cc
```

옵션 없이 만든 하드 링크는 원본 파일과 같은 i-노드를 가리킨다. `-s`로 만든 심볼릭 링크는 원본 파일의 경로명을 저장하는 별도의 특수 파일이다.

### 5. `file`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `file 파일` |
| 기능 | 파일의 종류에 대한 자세한 정보를 출력한다. |
| 옵션 | 없음 |
| 인자 | `파일`: 종류를 확인할 파일 |

#### 사용 예시

```bash
file cs1.txt
file a.out
```

텍스트 파일은 `ASCII text`처럼, 실행 파일은 실행 파일 형식 정보와 함께 출력된다.

### 6. `chmod`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `chmod [-R] 접근권한 파일`<br>`chmod [-R] 접근권한 디렉터리` |
| 기능 | 파일 또는 디렉터리의 접근권한을 변경한다. |
| 옵션 | `-R`: 지정한 디렉터리 아래의 모든 파일과 하위 디렉터리에도 적용 |
| 인자 | `접근권한`: 8진수 또는 기호로 표현한 권한<br>`파일`, `디렉터리`: 권한을 변경할 대상 |

#### 사용 예시

```bash
# 8진수로 권한 설정
chmod 644 cs1.txt

# 그룹의 쓰기 권한 제거
chmod g-w cs1.txt

# 기타 사용자의 읽기 권한 제거
chmod o-r cs1.txt

# 그룹에 쓰기, 기타 사용자에 읽기와 쓰기 권한 추가
chmod g+w,o+rw cs1.txt
```

8진수 방식에서는 `rwxr-xr-x`를 `755`, `rw-r--r--`를 `644`처럼 표현한다. 기호 방식에서는 사용자 범위 `u`, `g`, `o`, `a`와 연산자 `+`, `-`, `=`, 권한 `r`, `w`, `x`를 조합한다.

### 7. `chown`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `chown 사용자 파일`<br>`chown [-R] 사용자 디렉터리` |
| 기능 | 파일 또는 디렉터리의 소유자를 지정한 사용자로 변경한다. |
| 옵션 | `-R`: 지정한 디렉터리 아래의 모든 파일과 하위 디렉터리에도 적용 |
| 인자 | `사용자`: 새 소유자 이름<br>`파일`, `디렉터리`: 소유자를 변경할 대상 |

#### 사용 예시

```bash
chown gildong cs1.txt
chown -R gildong test
```

다른 사용자의 소유자로 바꾸려면 권한이 필요할 수 있다.

---

### 8. `chgrp`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `chgrp 그룹 파일`<br>`chgrp [-R] 그룹 디렉터리` |
| 기능 | 파일 또는 디렉터리가 속한 그룹을 지정한 그룹으로 변경한다. |
| 옵션 | `-R`: 지정한 디렉터리 아래의 모든 파일과 하위 디렉터리에도 적용 |
| 인자 | `그룹`: 새 그룹 이름<br>`파일`, `디렉터리`: 그룹을 변경할 대상 |

#### 사용 예시

```bash
chgrp cs cs1.txt
chgrp -R cs test
```

`chgrp`는 소유자는 그대로 두고 그룹만 변경할 때 사용한다.

### 9. `touch`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `touch 파일` |
| 기능 | 파일의 최종 접근 시간과 최종 수정 시간을 현재 시간으로 변경한다. |
| 옵션 | 없음 |
| 인자 | `파일`: 시간을 변경할 파일 |

#### 사용 예시

```bash
touch cs1.txt
ls -l cs1.txt
```

`ls -l`로 확인하면 파일 크기는 유지되고, 최종 수정 시간이 실행 시각으로 바뀐 것을 확인할 수 있다.

---

### 명령어 표기 형식

- `파일+`: 하나 이상의 파일을 입력할 수 있음
- `파일1 ... 파일n`: 여러 파일을 입력할 수 있음
- `[옵션]`: 선택적으로 입력하는 옵션
- 대괄호(`[ ]`)와 `+`는 사용법을 설명하기 위한 표기이며 실제 명령어에 입력하지 않는다.
