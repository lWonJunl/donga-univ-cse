### 1. `(( ))`로 산술 평가와 조건 판단

| 항목 | 내용 |
| --- | --- |
| 형식 | `$((산술식))`<br>`((산술식))` |
| 기능 | `$(( ))`는 계산 결과를 값으로 확장하고, `(( ))`는 산술 평가와 조건 판단에 사용한다. |
| 옵션 | 해당 없음. Bash 산술 문법 |
| 인자 | `산술식`: 정수 연산식. 변수 이름 앞의 `$`는 생략 가능 |

#### 사용 예시

```bash
a=10
b=20
c=$((a+b))
echo "$c"

# 자료의 wc2.bash 예시
if (( $# == 1 ))
then
    wc "$1"
else
    echo "사용법: $0 파일"
fi
```

`(( ))`는 계산 결과가 0이 아니면 참, 0이면 거짓이다. 명령어의 종료 상태는 참일 때 0이므로 계산값과 종료 상태를 구분한다.

| 연산자 | 의미 |
| --- | --- |
| `-`, `!` | 단항 음수, 논리 부정 |
| `*`, `/`, `%` | 곱셈, 정수 나눗셈, 나머지 |
| `+`, `-` | 덧셈, 뺄셈 |
| `<<`, `>>` | 비트 왼쪽 이동, 오른쪽 이동 |
| `<=`, `>=`, `<`, `>` | 대소 비교 |
| `==`, `!=` | 같음, 다름 |
| `&`, `^`, `\|` | 비트 AND, XOR, OR |
| `\|\|`, `&&` | 논리 OR, AND |

### 2. `if`, `elif`, `else`로 분기

| 항목 | 내용 |
| --- | --- |
| 형식 | `if ((조건)); then 명령어; elif ((조건)); then 명령어; else 명령어; fi` |
| 기능 | 조건을 순서대로 검사하여 처음 참인 분기를 실행한다. |
| 옵션 | 해당 없음. Bash 제어구조 |
| 인자 | `조건`: 참과 거짓을 판단할 산술식 |

#### 사용 예시

```bash
#!/bin/bash
echo -n '점수 입력: '
read score
if (( score >= 90 ))
then
    echo A
elif (( score >= 80 ))
then
    echo B
elif (( score >= 70 ))
then
    echo C
else
    echo '노력 요함'
fi
```

위의 `score1.bash`는 위에서부터 검사하여 처음 참인 분기만 실행한다. 예를 들어 85를 입력하면 `B`를 출력한다.

### 3. `case`

| 항목 | 내용 |
| --- | --- |
| 형식 | `case 값 in 패턴) 명령어;; ... esac` |
| 기능 | 값과 일치하는 패턴의 명령어를 실행한다. |
| 옵션 | 해당 없음. Bash 제어구조 |
| 인자 | `값`: 검사할 문자열<br>`패턴`: 일치 조건. `\|`로 여러 패턴 지정, `*`로 나머지 처리 |

#### 사용 예시

```bash
#!/bin/bash
# score2.bash
echo -n '점수 입력: '
read score
let grade=$score/10
case $grade in
    10|9) echo A;;
    8) echo B;;
    7) echo C;;
    *) echo '노력 요함';;
esac
```

`;;`는 해당 분기의 명령어 목록을 끝낸다. 예를 들어 정수 점수 85는 10으로 나눈 몫이 8이므로 `B`를 출력한다.

### 4. `for`와 `"$@"`

| 항목 | 내용 |
| --- | --- |
| 형식 | `for 변수 in 목록; do 명령어; done` |
| 기능 | 목록의 각 값을 변수에 대입하며 명령어를 반복 실행한다. |
| 옵션 | 해당 없음. Bash 반복문 |
| 인자 | `목록`: 배열 원소, 명령줄 인수, 파일 이름 등 |

#### 사용 예시

```bash
# 배열의 각 원소 처리
invitee=(lee kim choi)
for person in "${invitee[@]}"
do
    echo "$person"
done

# 스크립트에 전달된 각 인수 처리
for file in "$@"
do
    echo "$file"
done
```

자료의 초대 예시는 반복문 안에서 다음 파이프를 사용한다. `mail`이 설치되고 메일 전송 환경이 구성되어 있어야 하며, 실행하면 지정된 수신자에게 메일을 보낸다.

```bash
echo '초대의 글 : 오늘 저녁 식사 모임에 초대합니다.' | mail "${person}@gmail.com"
```

위의 `mail` 명령은 `person`에 수신자 이름이 지정되어 있을 때 사용하는 형식이다. `"${invitee[@]}"`와 `"$@"`는 각 원소나 인수에 포함된 공백을 보존한다.

### 5. `cut`으로 필드 추출

| 항목 | 내용 |
| --- | --- |
| 명령어 | `cut -d 구분문자 -f 필드번호` |
| 기능 | 입력의 각 줄을 구분문자로 나누고 지정한 필드를 출력한다. |
| 옵션 | `-d`: 필드 구분문자 지정<br>`-f`: 추출할 필드 번호 지정 |
| 인자 | `구분문자`: 한 문자<br>`필드번호`: 1부터 시작하는 번호 |

#### 사용 예시

자료의 `perm1.bash`는 각 일반 파일의 권한과 이름을 출력한다.

```bash
#!/bin/bash
if [ $# -eq 0 ]
then
    echo "사용법: $0 파일..."
    exit 1
fi
echo '사용권한 파일'
for file in "$@"
do
    if [ -f "$file" ]
    then
        fileinfo=$(ls -l "$file")
        perm=$(echo "$fileinfo" | cut -d' ' -f1)
        echo "$perm $file"
    fi
done
```

`cut -d' ' -f1`은 공백을 기준으로 첫 필드를 추출한다. 이 예시에서는 `ls -l` 출력 맨 앞의 파일 종류와 권한 부분을 사용한다.

### 7. `while`

| 항목 | 내용 |
| --- | --- |
| 형식 | `while 조건; do 명령어; done` |
| 기능 | 조건이 참인 동안 명령어를 반복 실행한다. |
| 옵션 | 해당 없음. Bash 반복문 |
| 인자 | `조건`: 각 반복 전에 검사할 조건 |

#### 사용 예시

```bash
#!/bin/bash
# power.bash: 2의 1승부터 10승까지 출력
let i=2
let j=1
while (( j <= 10 ))
do
    echo '2 ^' "$j" = "$i"
    let i*=2
    let j++
done
```

첫 출력은 `2 ^ 1 = 2`, 마지막 출력은 `2 ^ 10 = 1024`이다. 반복문 안에서 조건에 사용한 값을 변경하여 종료 조건에 도달하도록 한다.

### 8. `cat <<`과 메뉴 반복

| 항목 | 내용 |
| --- | --- |
| 형식 | `cat << 종료표시` |
| 기능 | 종료표시 전까지 작성한 여러 줄을 `cat`의 표준입력으로 전달하여 출력한다. |
| 옵션 | 해당 없음. `<<`는 here-document 입력 리다이렉션 |
| 인자 | `종료표시`: 입력의 끝을 나타내는 문자열 |

#### 사용 예시

```bash
#!/bin/bash
# menu.bash
echo '명령어 메뉴'
cat << MENU
d : 날짜 시간
l : 현재 디렉터리 내용
w : 사용자 보기
q : 끝냄
MENU
stop=0
while (( stop == 0 ))
do
    echo -n '? '
    read reply
    case $reply in
        d) date;;
        l) ls;;
        w) who;;
        q) stop=1;;
        *) echo '잘못된 선택';;
    esac
done
```

마지막 `MENU`는 앞에 공백을 넣지 않고 단독으로 작성한다. `q`를 입력하면 `stop`이 1이 되어 반복이 끝난다.

### 11. 함수 정의와 호출

| 항목 | 내용 |
| --- | --- |
| 형식 | `함수이름() { 명령어; }`<br>`함수이름 [인수...]` |
| 기능 | 여러 명령어를 함수로 묶어 이름으로 호출한다. |
| 옵션 | 자료의 예시에서는 사용하지 않음 |
| 인자 | `인수`: 함수 안에서 `$1`, `$2` 등으로 참조할 값 |

#### 사용 예시

```bash
#!/bin/bash
# lshead.bash
lshead()
{
    echo "함수 시작, 매개변수 $1"
    date
    echo "디렉터리 $1 내의 처음 3개 파일만 리스트"

}
echo '안녕하세요'
lshead /tmp
```

함수 안의 `$1`은 함수 호출 시 전달한 첫 인수인 `/tmp`이다. 자료의 `head -4`는 처음 4줄을 출력하며, 예시에서는 합계 줄 1개와 항목 3개에 해당한다. 실제 항목 수나 출력은 디렉터리 내용에 따라 달라진다.

### 12. `cd`와 `for`로 디렉터리 항목 처리

| 항목 | 내용 |
| --- | --- |
| 명령어·형식 | `cd 디렉터리`<br>`for file in *; do 명령어; done` |
| 기능 | 대상 디렉터리로 이동한 뒤 이름 패턴 `*`로 각 항목을 처리한다. |
| 옵션 | 자료의 예시에서는 사용하지 않음 |
| 인자 | `디렉터리`: 처리할 위치<br>`*`: 기본 설정에서 숨김 항목을 제외한 이름으로 확장 |

#### 사용 예시

자료의 `count2.bash`를 기준으로 파일과 디렉터리 개수를 센다.

```bash
#!/bin/bash
if [ $# -eq 0 ]
then
    dir="."
else
    dir=$1
fi
if [ ! -d "$dir" ]
then
    echo "$0: $dir 디렉터리 아님"
    exit 1
fi
let fcount=0
let dcount=0
let others=0
echo "$dir:"
cd "$dir" || exit 1
for file in *
do
    # 일치하는 이름이 없을 때 그대로 남는 *는 세지 않음
    if [ -e "$file" ] || [ -L "$file" ]
    then
        if [ -f "$file" ]
        then
            let fcount++
        elif [ -d "$file" ]
        then
            let dcount++
        else
            let others++
        fi
    fi
done
echo "파일: $fcount 디렉터리: $dcount 기타: $others"
```

자료의 코드를 공백이 있는 경로와 빈 디렉터리에서도 사용할 수 있도록 따옴표, 이동 실패 처리, 항목 존재 검사를 보완했다. 보완에 사용한 `-L`은 심볼릭 링크 자체를 검사하므로 대상이 사라진 링크도 누락하지 않는다.

`-f`, `-d`는 심볼릭 링크의 대상을 검사한다. 따라서 일반 파일을 가리키는 링크는 파일, 디렉터리를 가리키는 링크는 디렉터리로 집계된다. 이 예시는 기본 Bash 설정에서 숨김 항목을 세지 않는다.

### 13. 스크립트 자기 호출과 `ls -s`

| 항목 | 내용 |
| --- | --- |
| 명령어·형식 | `ls -s`<br>`스크립트경로 하위디렉터리` |
| 기능 | 각 디렉터리의 할당 공간을 출력하고, 같은 스크립트를 하위 디렉터리에 대해 다시 실행한다. |
| 옵션 | `ls -s`: 각 항목에 할당된 공간을 블록 단위로 표시 |
| 인자 | `스크립트경로`: 재호출할 스크립트의 경로<br>`하위디렉터리`: 다음 처리 대상 |

#### 사용 예시

자료의 `lssr.bash`는 다음 흐름으로 작성되어 있다.

```bash
# 스크립트의 dir에 대상 디렉터리가 지정된 상태
if [ ! -d "$dir" ]
then
    echo "$0: $dir 디렉터리 아님"
    exit 1
fi
cd "$dir" || exit 1
echo -e "\n $PWD :"
ls -s
for x in *
do
    if [ -d "$x" ]
    then
        # 자료에 적힌 스크립트 경로. 실제 저장한 절대 경로로 바꿔 사용
        /home/chang/bash/lssr.bash "$x"
    fi
done
```

`$PWD`는 현재 작업 디렉터리이다. 자료의 `/home/chang/bash/lssr.bash`는 예시 경로이므로 그대로 존재한다고 가정하지 않는다. `cd`로 위치를 바꾸므로 재호출에는 저장 위치를 가리키는 경로가 필요하다.

`ls -s`는 파일 내용의 바이트 수가 아니라 할당된 공간을 표시한다. 이 단순 재귀 예시는 숨김 하위 디렉터리를 제외하며, 디렉터리 심볼릭 링크를 따라가면 순환할 수 있다.

### 재귀 호출의 경로 지정

자료 68쪽은 고정된 `/home/chang/bash/lssr.bash` 경로 대신 스크립트의 절대 경로를 미리 구하는 방법을 제시한다. 디렉터리를 이동하기 전에 경로를 구해야 한다.

```bash
script=$(realpath -- "${BASH_SOURCE[0]}")
cd "$dir" || exit 1
for x in *
do
    if [ -d "$x" ]
    then
        bash "$script" "$x"
    fi
done
```

`${BASH_SOURCE[0]}`은 스크립트의 경로를 나타내며 `realpath`는 이를 절대 경로로 변환한다. 디렉터리 심볼릭 링크를 따라가면 순환할 수 있다.

### 명령어 표기 형식

- `[옵션]`, `[인수]`: 선택적으로 입력하는 항목. 조건 검사의 실제 명령어인 `[ 조건식 ]`와 구분한다.
- `파일...`, `인수...`: 여러 파일이나 인수를 지정할 수 있다는 표기
- `변수이름`, `파일`, `디렉터리`, `스크립트`: 실제 이름이나 경로로 바꾸어 입력하는 자리표시자
- `~`, `$HOME`: 현재 사용자의 홈 디렉터리
- `.`, `./파일`: 현재 디렉터리, 현재 디렉터리 안의 파일 경로
- `$변수`, `${변수}`: 변수 값 참조
- `$(명령어)`, 백틱: 명령어의 표준출력을 값으로 사용하는 명령 치환
- `$((산술식))`: 산술 계산 결과를 값으로 사용하는 산술 확장
- `|`: 앞 명령어의 표준출력을 뒤 명령어의 표준입력으로 전달하는 파이프
- `>`: 표준출력을 파일에 저장하는 리다이렉션. 기존 내용은 덮어씀
- `#`: Bash 코드에서 주석 시작. 첫 줄의 `#!`는 스크립트 해석기 지정
- 자료의 `$`, `#`, `>` 프롬프트: 일반 사용자, 관리자, 여러 줄 입력 대기 표시. 명령어에 포함하여 입력하지 않음
- 자료의 굽은 따옴표와 긴 대시는 실행 가능한 ASCII 따옴표와 `-`로 바꾸었다.
- 사용 예시와 설명의 출력값은 교재 예시 또는 코드에서 예상되는 값이며 실제 실습 실행 기록은 아니다.
