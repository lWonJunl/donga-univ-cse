## 배운 명령어

### 1. `more`로 Bash 시작 파일 확인

| 항목 | 내용 |
| --- | --- |
| 명령어 | `more 파일` |
| 기능 | Bash가 시작할 때 읽는 설정 파일의 내용을 화면 단위로 확인한다. |
| 옵션 | 자료의 예시에서는 사용하지 않음 |
| 인자 | `파일`: 확인할 시스템 또는 사용자 시작 파일 |

#### 사용 예시

```bash
more /etc/profile
more /etc/bash.bashrc
more ~/.profile
more ~/.bashrc
```

| 시작 파일 | 역할 |
| --- | --- |
| `/etc/profile` | 로그인 쉘의 시스템 전체 설정 |
| `/etc/bash.bashrc` | Ubuntu의 대화형 Bash 시스템 전체 설정. 배포판에 따라 이름과 사용 방식이 다를 수 있음 |
| `~/.bash_profile` | 로그인 쉘의 사용자 설정. 가장 먼저 확인 |
| `~/.bash_login` | `~/.bash_profile`이 없을 때 확인 |
| `~/.profile` | 앞의 두 사용자 파일이 없을 때 확인 |
| `~/.bashrc` | 비로그인 대화형 Bash의 사용자 설정. 별명, 함수, 프롬프트 등을 설정 |

로그인 Bash는 `/etc/profile`을 읽고, 사용자 로그인 설정 파일 중 처음 발견한 읽을 수 있는 파일 하나를 읽는다. 자료의 Ubuntu 예시에서는 `/etc/profile`이 `/etc/bash.bashrc`를, `~/.profile`이 `~/.bashrc`를 불러온다.

`bash 파일`과 같은 비대화형 실행에서는 위의 대화형 시작 파일들을 기본적으로 읽지 않는다. `BASH_ENV`가 설정되어 있으면 지정된 파일을 읽을 수 있다. 자료 5~13쪽.

### 2. `.`으로 설정 파일 불러오기

| 항목 | 내용 |
| --- | --- |
| 명령어 | `. 파일` |
| 기능 | 파일에 작성된 명령어를 현재 쉘에서 실행한다. |
| 옵션 | 자료의 예시에서는 사용하지 않음 |
| 인자 | `파일`: 현재 쉘에 적용할 설정 파일 |

#### 사용 예시

```bash
# 자료의 ~/.profile 안에서 사용하는 형식
if [ -f "$HOME/.bashrc" ]
then
    . "$HOME/.bashrc"
fi
```

`.` 뒤에는 공백을 둔다. `bash 파일`처럼 자식 쉘을 실행하는 방식과 달리 현재 쉘에 변수나 별명 설정이 반영된다. 자료 7, 10쪽.

### 3. `PS1`으로 프롬프트 설정

| 항목 | 내용 |
| --- | --- |
| 형식 | `PS1='문자열'` |
| 기능 | 대화형 Bash가 명령어 입력을 기다릴 때 표시하는 기본 프롬프트를 지정한다. |
| 옵션 | 해당 없음. 변수 대입 형식 |
| 인자 | `문자열`: 프롬프트에 표시할 문자와 특수 문자열 |

#### 사용 예시

```bash
echo "$PS1"
PS1='Linux> '
PS1='\w\$ '
PS1='[\u] \w> '
PS1='\d \t> '
PS1='\u@\h:\w\$ '
```

| 특수 문자열 | 의미 |
| --- | --- |
| `\u` | 현재 사용자 이름 |
| `\h`, `\H` | 짧은 호스트명, 전체 호스트명 |
| `\w`, `\W` | 현재 작업 디렉터리 경로, 마지막 디렉터리 이름 |
| `\d`, `\t` | 날짜, 24시간 형식의 시각 |
| `\$` | 일반 사용자이면 `$`, root이면 `#` |
| `\n` | 줄바꿈 |
| `\[`, `\]` | 색상 코드처럼 화면 너비를 차지하지 않는 제어 문자열의 시작과 끝 |

```bash
# 사용자와 호스트 부분을 초록색으로 표시
PS1='\[\e[32m\]\u@\h\[\e[0m\]:\w\$ '
```

현재 쉘에서 대입한 설정은 해당 세션에 적용된다. 새 터미널에서도 사용하려면 `~/.bashrc`에 기록한다. 자료 8쪽.

### 6. `history`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `history [개수]`<br>`history -r [파일]` |
| 기능 | 기억된 명령어 목록을 확인하거나 히스토리 파일을 읽는다. |
| 옵션 | `-r`: 히스토리 파일의 내용을 현재 목록에 추가 |
| 인자 | `개수`: 최근에 입력한 명령어 중 출력할 개수<br>`파일`: 읽을 히스토리 파일. 생략하면 `$HISTFILE` 사용 |

#### 사용 예시

```bash
history
history 10
HISTSIZE=100
HISTFILESIZE=100
set | grep HIST
env | grep HIST
```

`HISTSIZE`는 메모리에 기억할 명령어 수, `HISTFILESIZE`는 히스토리 파일에 저장할 최대 줄 수를 설정한다. `set`은 쉘 변수를, `env`는 환경변수를 확인하는 데 사용하므로 export하지 않은 `HISTSIZE`는 `env` 출력에 나타나지 않을 수 있다.

자료 16쪽의 `history [-rh]` 중 `-h`는 Bash의 `history` 옵션이 아니다. 설치된 Bash의 `help history`를 기준으로 정리했다.

### 7. `!`로 이전 명령어 재실행

| 항목 | 내용 |
| --- | --- |
| 형식 | `!!`, `!번호`, `!시작문자열`, `!?포함문자열?` |
| 기능 | 대화형 Bash의 히스토리에서 명령어를 찾아 다시 실행한다. |
| 옵션 | 해당 없음. 히스토리 확장 문법 |
| 인자 | `번호`: 이벤트 번호<br>`시작문자열`, `포함문자열`: 이전 명령어를 찾을 문자열 |

#### 사용 예시

```bash
!!
!20
!gcc
!?test.c?
```

`!!`는 바로 전 명령어, `!20`은 이벤트 번호 20인 명령어를 재실행한다. `!gcc`는 `gcc`로 시작하는 가장 최근 명령어, `!?test.c?`는 `test.c`를 포함하는 가장 최근 명령어를 재실행한다. 자료 17쪽.

### 8. 변수 대입과 `echo`

| 항목 | 내용 |
| --- | --- |
| 형식 | `변수이름=값`<br>`echo [-n] 문자열...` |
| 기능 | 변수에 문자열을 저장하고 변수 값이나 문자열을 출력한다. |
| 옵션 | `echo -n`: 마지막 줄바꿈 생략<br>`echo -e`: `\n` 등의 이스케이프 해석 |
| 인자 | `값`: 저장할 문자열<br>`문자열`: 출력할 내용. `$변수이름`으로 변수 값 참조 |

#### 사용 예시

```bash
city=seoul
echo "$city"
city=pusan
country=대한민국 city=서울
echo "$country $city"
address="서울시 용산구"
echo "$address"
echo -n '점수 입력: '
```

변수 대입의 `=` 앞뒤에는 공백을 넣지 않는다. 여러 단어를 하나의 값으로 저장할 때는 따옴표로 묶는다. `"$변수"`는 공백을 포함한 값을 하나의 인자로 전달한다. 자료 19~20, 30, 64쪽.

### 9. 배열 변수

| 항목 | 내용 |
| --- | --- |
| 형식 | `이름=(값1 값2 ...)`<br>`이름[인덱스]=값` |
| 기능 | 하나의 변수에 여러 값을 저장하고 원소별로 참조한다. |
| 옵션 | 해당 없음. Bash 배열 문법 |
| 인자 | `인덱스`: 원소 번호. 자료의 배열은 0부터 시작 |

#### 사용 예시

```bash
cities=(서울 부산 목포)
echo "${cities[*]}"
echo "${cities[1]}"
echo "${#cities[@]}"
cities[3]=제주
echo "${cities[3]}"
```

| 참조 형식 | 의미 |
| --- | --- |
| `${cities[i]}` | 인덱스가 `i`인 원소 |
| `"${cities[*]}"` | 모든 원소를 하나의 문자열 인자로 확장. 기본 구분자는 공백 |
| `"${cities[@]}"` | 각 원소를 별개의 인자로 확장 |
| `${#cities[*]}`, `${#cities[@]}` | 저장된 원소 개수 |

초기 배열에서 인덱스 1의 값은 `부산`이고 원소 개수는 3이다. 아직 대입하지 않은 `${cities[3]}`은 빈 값으로 확장되며, `제주`를 대입하면 원소가 추가된다. 자료 21~22쪽.

### 10. `read`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `read 변수1 ... 변수n` |
| 기능 | 표준입력에서 한 줄을 읽어 단어들을 변수에 순서대로 저장한다. |


첫 예시에서 `x`에는 `Merry`, `y`에는 `Christmas !`가 저장된다. 변수를 하나만 지정하면 기본 공백 구분 문자가 앞뒤에서 제거된 나머지 줄이 그 변수에 저장된다. 자료 23쪽.

### 11. `export`와 환경변수

| 항목 | 내용 |
| --- | --- |
| 명령어 | `export 변수이름` |
| 기능 | 변수를 이후 실행되는 자식 프로세스에 전달할 환경변수로 지정한다. |
| 옵션 | 자료의 예시에서는 사용하지 않음 |
| 인자 | `변수이름`: 환경변수로 전달할 변수 |

#### 사용 예시

```bash
country=대한민국 city=서울
export country
echo "$country $city"
bash
# 새로 시작한 자식 쉘에서 실행
echo "$country $city"
# Ctrl+D로 자식 쉘을 끝낸 후 부모 쉘에서 실행
echo "$country $city"
```

자료의 예시는 `country`, `city`에 기존 export 속성이 없는 상태를 가정한다. 자식 쉘에는 export한 `country`만 전달되며, 부모 쉘에는 두 변수 모두 남아 있다. 자료에서 말하는 지역변수는 export하지 않은 쉘 변수로, 함수의 `local` 변수와는 구분한다.

| 변수 | 의미 |
| --- | --- |
| `$USER` | 사용자 이름 |
| `$TERM` | 터미널 종류 |
| `$PATH` | 외부 명령어를 검색할 디렉터리 목록 |
| `$HOME` | 홈 디렉터리 |
| `$SHELL` | 로그인 쉘의 경로. 현재 실행 중인 쉘과 항상 같지는 않음 |
| `$MAIL` | 메일함 경로 |
| `$HOSTNAME` | 호스트 이름 |
| `$PS1` | 기본 프롬프트 형식 |

```bash
echo "홈 = $HOME 사용자 = $USER 쉘 = $SHELL"
echo "터미널 = $TERM 경로 리스트 = $PATH"
```

위 변수들이 모두 환경변수인 것은 아니다. export 여부에 따라 자식 프로세스 전달 여부가 달라진다. `PATH`는 디렉터리를 `:`으로 구분하며, 현재 디렉터리 `.`을 추가하면 의도하지 않은 프로그램이 실행될 수 있으므로 자료에서는 `./프로그램`처럼 경로를 명시하도록 안내한다. 자료 11, 25~27쪽.

### 12. `bash`와 `chmod`로 스크립트 실행

| 항목 | 내용 |
| --- | --- |
| 명령어 | `bash [스크립트 [인수...]]`<br>`chmod +x 스크립트`<br>`./스크립트 [인수...]` |
| 기능 | Bash를 시작하거나 스크립트를 실행한다. `chmod`는 직접 실행할 수 있도록 실행권한을 추가한다. |
| 옵션 | `chmod +x`: 실행권한 추가 |
| 인자 | `스크립트`: 명령어를 작성한 파일<br>`인수`: 스크립트에 전달할 값 |

#### 사용 예시

`state.bash` 파일에 다음 내용을 작성한다.

```bash
#!/bin/bash
# 현재 시간, 사용자, 시스템 상태 확인
echo -n '현재 시간: '
date
echo '현재 사용자: '
who
echo '시스템 현재 상황: '
uptime
```

```bash
chmod +x state.bash
./state.bash

# Bash에 파일을 전달하여 실행하는 방법
bash state.bash
```

첫 줄의 `#!/bin/bash`는 직접 실행할 때 사용할 해석기를 지정한다. `./state.bash`는 실행권한이 필요하고, `bash state.bash`는 Bash가 파일을 읽어 실행하므로 스크립트 자체의 실행권한은 필요하지 않다.

`date`는 날짜와 시각, `who`는 로그인 사용자, `uptime`은 가동 시간과 부하 등의 정보를 출력한다. 출력값은 실행 환경과 시점에 따라 달라진다. 자료 29~30쪽.

### 13. 특수 매개변수

| 항목 | 내용 |
| --- | --- |
| 형식 | `$0`, `$1`~`$9`, `$*`, `$@`, `$#`, `$$` |
| 기능 | 스크립트 이름, 명령줄 인수, 인수 개수, 프로세스 번호를 참조한다. |
| 옵션 | 해당 없음. 매개변수 확장 문법 |
| 인자 | 스크립트를 실행할 때 전달한 명령줄 인수 |

#### 사용 예시

`builtin.bash` 파일의 내용이다.

```bash
#!/bin/bash
echo "이 스크립트 이름: $0"
echo "첫 번째 명령줄 인수: $1"
echo "모든 명령줄 인수: $*"
echo "인수 개수: $#"
echo "이 스크립트를 실행하는 프로세스 번호: $$"
```

```bash
bash builtin.bash hello shell
```

| 매개변수 | 의미 |
| --- | --- |
| `$0` | 스크립트 이름 또는 호출 경로 |
| `$1`~`$9` | 첫 번째부터 아홉 번째 명령줄 인수 |
| `"$*"` | 모든 인수를 하나의 문자열로 확장 |
| `"$@"` | 각 인수를 별개의 인자로 확장. 공백이 있는 인수를 보존할 때 사용 |
| `$#` | 명령줄 인수 개수 |
| `$$` | 쉘의 프로세스 번호 |

이 예시의 `$#`은 2이다. 프로세스 번호는 실행할 때 달라진다. 자료 28, 52쪽.

### 14. `[ ]`로 조건 검사

| 항목 | 내용 |
| --- | --- |
| 명령어 | `[ 조건식 ]` |
| 기능 | 정수, 문자열, 파일 조건을 검사하여 참 또는 거짓에 해당하는 종료 상태를 반환한다. |
| 옵션 | 해당 없음. 아래 표의 조건 연산자 사용 |
| 인자 | `조건식`: 검사할 값과 연산자 |

#### 사용 예시

```bash
if [ $# -eq 1 ]
then
    wc "$1"
fi
```

`[`와 `]`는 조건식과 공백으로 구분한다. 문자열이나 파일 경로를 참조하는 변수는 `"$변수"`처럼 묶는다. `[ ]`는 조건 결과를 화면에 출력하지 않으며 참이면 종료 상태 0을 반환한다.

| 정수 비교 | 의미 |
| --- | --- |
| `정수1 -eq 정수2` | 같음 |
| `정수1 -ne 정수2` | 다름 |
| `정수1 -gt 정수2` | 큼 |
| `정수1 -ge 정수2` | 크거나 같음 |
| `정수1 -lt 정수2` | 작음 |
| `정수1 -le 정수2` | 작거나 같음 |

| 문자열 비교 | 의미 |
| --- | --- |
| `문자열1 == 문자열2` | 두 문자열이 같음. 자료의 Bash 형식 |
| `문자열1 != 문자열2` | 두 문자열이 다름 |
| `-n 문자열` | 문자열 길이가 0이 아님 |
| `-z 문자열` | 문자열 길이가 0임 |

| 파일 검사 | 의미 |
| --- | --- |
| `-a 파일`, `-e 파일` | 존재함. 예시에서는 `-e` 사용 |
| `-r 파일`, `-w 파일`, `-x 파일` | 현재 사용자가 읽기, 쓰기, 실행할 수 있음 |
| `-O 파일` | 현재 사용자가 파일 소유자임 |
| `-s 파일` | 존재하고 크기가 0보다 큼 |
| `-f 파일` | 일반 파일임 |
| `-d 파일` | 디렉터리임 |

```bash
file=cs1.txt
if [ -e "$file" ]
then
    wc "$file"
else
    echo '오류! 파일 없음'
fi
```

### 23. `cut`으로 필드 추출

자료의 `perm1.bash`는 각 일반 파일의 권한과 이름을 출력한다.

| 명령어 | `bash -vx 스크립트 [인수...]` |
| 기능 | 스크립트 입력 내용이나 실행 과정을 출력하면서 실행한다. |
| 옵션 | `-v`: 읽어 들인 쉘 입력 줄 출력<br>`-x`: 확장 후 실행할 명령어와 인수 추적 출력 |
| 인자 | `스크립트`: 확인할 Bash 파일<br>`인수`: 스크립트에 전달할 값 |

#### 사용 예시

```bash
bash -v menu.bash
bash -x menu.bash
bash -vx menu.bash
```

이 옵션들은 내용을 표시하면서 실제 스크립트도 실행한다. 입력을 받는 스크립트는 디버깅 중에도 입력을 기다린다. 자료 58쪽.

### 29. 함수 정의와 호출

| 항목 | 내용 |
| --- | --- |
| 형식 | `함수이름() { 명령어; }`<br>`함수이름 [인수...]` |
| 기능 | 여러 명령어를 함수로 묶어 이름으로 호출한다. |
| 옵션 | 자료의 예시에서는 사용하지 않음 |
| 인자 | `인수`: 함수 안에서 `$1`, `$2` 등으로 참조할 값 |

#### 사용 예시

```bash
#!/bin/bash
# lshead.bash
lshead()
{
    echo "함수 시작, 매개변수 $1"
    date
    echo "디렉터리 $1 내의 처음 3개 파일만 리스트"
    ls -l "$1" | head -4
}
echo '안녕하세요'
lshead /tmp
```

함수 안의 `$1`은 함수 호출 시 전달한 첫 인수인 `/tmp`이다. 자료의 `head -4`는 처음 4줄을 출력하며, 예시에서는 합계 줄 1개와 항목 3개에 해당한다. 실제 항목 수나 출력은 디렉터리 내용에 따라 달라진다. 자료 59~60쪽.

### 30. `cd`와 `for`로 디렉터리 항목 처리

| 항목 | 내용 |
| --- | --- |
| 명령어·형식 | `cd 디렉터리`<br>`for file in *; do 명령어; done` |
| 기능 | 대상 디렉터리로 이동한 뒤 이름 패턴 `*`로 각 항목을 처리한다. |
| 옵션 | 자료의 예시에서는 사용하지 않음 |
| 인자 | `디렉터리`: 처리할 위치<br>`*`: 기본 설정에서 숨김 항목을 제외한 이름으로 확장 |

#### 사용 예시

자료의 `count2.bash`를 기준으로 파일과 디렉터리 개수를 센다.

```bash
#!/bin/bash
if [ $# -eq 0 ]
then
    dir="."
else
    dir=$1
fi
if [ ! -d "$dir" ]
then
    echo "$0: $dir 디렉터리 아님"
    exit 1
fi
let fcount=0
let dcount=0
let others=0
echo "$dir:"
cd "$dir" || exit 1
for file in *
do
    # 일치하는 이름이 없을 때 그대로 남는 *는 세지 않음
    if [ -e "$file" ] || [ -L "$file" ]
    then
        if [ -f "$file" ]
        then
            let fcount++
        elif [ -d "$file" ]
        then
            let dcount++
        else
            let others++
        fi
    fi
done
echo "파일: $fcount 디렉터리: $dcount 기타: $others"
```

자료의 코드를 공백이 있는 경로와 빈 디렉터리에서도 사용할 수 있도록 따옴표, 이동 실패 처리, 항목 존재 검사를 보완했다. 보완에 사용한 `-L`은 심볼릭 링크 자체를 검사하므로 대상이 사라진 링크도 누락하지 않는다.

`-f`, `-d`는 심볼릭 링크의 대상을 검사한다. 따라서 일반 파일을 가리키는 링크는 파일, 디렉터리를 가리키는 링크는 디렉터리로 집계된다. 이 예시는 기본 Bash 설정에서 숨김 항목을 세지 않는다. 자료 61~63쪽.

### 31. 스크립트 자기 호출과 `ls -s`

| 항목 | 내용 |
| --- | --- |
| 명령어·형식 | `ls -s`<br>`스크립트경로 하위디렉터리` |
| 기능 | 각 디렉터리의 할당 공간을 출력하고, 같은 스크립트를 하위 디렉터리에 대해 다시 실행한다. |
| 옵션 | `ls -s`: 각 항목에 할당된 공간을 블록 단위로 표시 |
| 인자 | `스크립트경로`: 재호출할 스크립트의 경로<br>`하위디렉터리`: 다음 처리 대상 |

#### 사용 예시

자료의 `lssr.bash`는 다음 흐름으로 작성되어 있다.

```bash
# 스크립트의 dir에 대상 디렉터리가 지정된 상태
if [ ! -d "$dir" ]
then
    echo "$0: $dir 디렉터리 아님"
    exit 1
fi
cd "$dir" || exit 1
echo -e "\n $PWD :"
ls -s
for x in *
do
    if [ -d "$x" ]
    then
        # 자료에 적힌 스크립트 경로. 실제 저장한 절대 경로로 바꿔 사용
        /home/chang/bash/lssr.bash "$x"
    fi
done
```

`$PWD`는 현재 작업 디렉터리이다. 자료의 `/home/chang/bash/lssr.bash`는 예시 경로이므로 그대로 존재한다고 가정하지 않는다. `cd`로 위치를 바꾸므로 재호출에는 저장 위치를 가리키는 경로가 필요하다.

`ls -s`는 파일 내용의 바이트 수가 아니라 할당된 공간을 표시한다. 이 단순 재귀 예시는 숨김 하위 디렉터리를 제외하며, 디렉터리 심볼릭 링크를 따라가면 순환할 수 있다. 자료 64쪽.

### 32. `for`와 `mv`로 확장자 일괄 변경

| 항목 | 내용 |
| --- | --- |
| 명령어·형식 | `mv 원래이름 새이름`<br>`${변수%패턴}` |
| 기능 | 반복문으로 파일을 처리하고 변수 값의 끝에서 패턴과 일치하는 가장 짧은 부분을 제거하여 새 이름을 만든다. |
| 옵션 | 자료의 예시에서는 사용하지 않음 |
| 인자 | `원래이름`, `새이름`: 변경 전후 이름<br>`패턴`: 끝에서 제거할 문자열 패턴 |

#### 사용 예시

```bash
# 현재 디렉터리의 .txt 파일 이름을 .bak으로 변경하는 자료 예시
for f in *.txt
do
    mv "$f" "${f%.txt}.bak"
done
```

`report1.txt`에서 `${f%.txt}`는 `report1`이므로 새 이름은 `report1.bak`이 된다. 이 명령은 실제 파일 이름을 바꾸며, 같은 이름의 대상 파일이 이미 있으면 덮어쓸 수 있다. 자료의 예시는 일치하는 `.txt` 파일이 있는 경우를 가정한다. 자료 2쪽.

### 명령어 표기 형식

- `[옵션]`, `[인수]`: 선택적으로 입력하는 항목. 조건 검사의 실제 명령어인 `[ 조건식 ]`와 구분한다.
- `파일...`, `인수...`: 여러 파일이나 인수를 지정할 수 있다는 표기
- `변수이름`, `파일`, `디렉터리`, `스크립트`: 실제 이름이나 경로로 바꾸어 입력하는 자리표시자
- `~`, `$HOME`: 현재 사용자의 홈 디렉터리
- `.`, `./파일`: 현재 디렉터리, 현재 디렉터리 안의 파일 경로
- `$변수`, `${변수}`: 변수 값 참조
- `$(명령어)`, 백틱: 명령어의 표준출력을 값으로 사용하는 명령 치환
- `$((산술식))`: 산술 계산 결과를 값으로 사용하는 산술 확장
- `|`: 앞 명령어의 표준출력을 뒤 명령어의 표준입력으로 전달하는 파이프
- `>`: 표준출력을 파일에 저장하는 리다이렉션. 기존 내용은 덮어씀
- `#`: Bash 코드에서 주석 시작. 첫 줄의 `#!`는 스크립트 해석기 지정
- 자료의 `$`, `#`, `>` 프롬프트: 일반 사용자, 관리자, 여러 줄 입력 대기 표시. 명령어에 포함하여 입력하지 않음
- 자료의 굽은 따옴표와 긴 대시는 실행 가능한 ASCII 따옴표와 `-`로 바꾸었다.
- 사용 예시와 설명의 출력값은 교재 예시 또는 코드에서 예상되는 값이며 실제 실습 실행 기록은 아니다.
